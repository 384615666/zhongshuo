## 2. 关键行为说明（语义）

### 项目行点击（§五）
- **名称、文件夹图标、行内空白、左侧箭头**：都只做"展开/收起"，只改项目树 —— 不跳页面、不切当前项目、不动主内容。原来"点名称 = 切换项目 + 跳第一个房间"的行为已移除。
- **`…`**：打开项目操作菜单（阻止冒泡，不会同时收起/展开）。**`+`**：打开"新建对话池"，项目已绑定，不再问归属（复用项目页那套 `CreateRoomModal`，创建后进新房间）。
- **切换当前项目只剩一处**：顶栏项目管理菜单里点项目名 = 显式切换（沿用既有落点与补选逻辑）。

### 私信范围（§三）
- 一级「私信」是**跨项目的会话聚合**，不是把项目上下文合并掉：每条会话仍带自己的 `projectId` / `conversationId` / audience；两个项目里的同名 Codex 是**两条独立会话**（种子里各有一条，用来看护"不合并"这条规则）。
- 默认列全部**日常项目**的会话；按项目筛选后只列那一个（含归档项目的历史，只读）；会话头部与每行都标明所属项目。
- 未读聚合：项目树折叠汇总**只算房间未读**（私信行已搬走，避免"展开后找不到未读来源"）；私信未读由一级入口的小蓝点承担，`markDmRead` 让点能被消耗（此前私信 unread 只有发送消息才清零）。
- 旧链接 `/dm`（全部项目）、`/project/:id/dm`（预置该项目筛选）、`/dm/:memberId`（按成员实体解析项目）都仍能打开。

### 归档 / 隐藏 / 移除的语义（互不混淆）
| 动作 | 语义 | 数据 |
|---|---|---|
| **隐藏**（顶栏勾选框） | 只影响侧栏显示 | 什么都不动 |
| **归档项目** | 退出日常项目树，历史保留**只读**；其下房间不能发消息、建任务、被唤醒；可在归档管理恢复 | 保留；恢复时**不动**各自单独归档的房间，**不重放**旧任务 |
| **移除项目** | 从应用项目列表解除关联（不删磁盘、不删会话/任务记录），设置里可**重新关联** | 全部保留（原型内存态，`removedAt` 仅表示"不列出"） |

归档前置检查与房间归档同一口径（`ACTIVE / WAITING_USER / BLOCKED`）：有未结束工作时**拒绝**并给出"去任务看板查看"的入口，不强停、不丢任务。归档当前正在查看的项目时跳到 `/archive?project=<id>`（它现在所在的位置），不留失效路由。

原生能力：`在资源管理器中打开` 走 Electron `shell.openPath`；浏览器宿主**明确说明没有这个能力**，目录失效时给出准确反馈与既有"重新定位项目目录"入口。

6. **触屏宿主**（`@media (hover: none)` 常驻显示 `…`/`+`）只写了样式分支，**没有真机触屏验证**。
