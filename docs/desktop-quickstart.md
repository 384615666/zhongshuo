# 众说 Windows 日常使用

从本包的 `start-desktop.bat` 启动。首次打开自己的项目文件夹；再次启动会保留项目与阅读记录。不要同时用两个版本打开同一数据根。

## 继续使用旧数据

先正常关闭旧版和新版，并保留一份完整旧包及其全部数据备份。保留旧包及旧数据原件；确认新包尚未开始使用，再把旧包完整的 `server-data` 文件夹（包括其中的 `electron-user-data`、附件、草稿及未知信封）复制到新包同名位置。不要只复制 SQLite 文件，也不要把两个已经使用过的数据根混合覆盖。已使用的新根先另存完整副本；不确定根位置时可在“设置 → 数据与存储”查看。

数据与 CLI 登录配置是两件事：新包沿用本机现有 CLI 配置，不自动重设账号。升级被拒绝时查看诊断；不要删除版本标记、解除保护或用旧程序强开新数据。回退使用升级前完整数据副本和匹配旧程序，不能把新版新增记录直接混入旧根。

## 配置成员与提问

打开“成员管理”，为成员配置本机可用的 Claude/Codex 程序及实际模型 ID，选择支持的思考等级并保存。配置保存与模型真实可用分别显示；缺程序或渠道请求失败时按就地原因处理。

新任务默认使用 CLI 完整权限，可以读写电脑并执行命令；显式只读选项保留，旧任务和已保存的限制不会悄悄升级。项目改动集只覆盖项目范围，不能记录整台电脑的全部修改。

显式计划档本次止于方案，可能提交一份待你审阅的文字方案；这不代表目标文件已经创建，也不会把旧只读任务自动提权。查看回答中的实际执行与未执行原因后，再明确发起允许执行的新请求。

房间中选择一位执行成员，再输入问题或任务；私信直接发送给该成员。普通对话在同一回复串默认由原执行成员结合前文继续回答；明确选择“仅记录”只保存。没有正文也可发送附件。选择图片后会自动传递实际图片，不需要选择工程认证资格；本地预览和“仅记录”独立可用。上传成功与模型是否成功理解图片分开显示。

思考等级来自当前 CLI/模型支持列表并传入请求；渠道未回报实际有效强度时，不显示为已认证。模板创建的是独立配置快照，修改模板不会同步改动已有成员，也不复制凭据或旧会话。

## 文件、返工与验收

在成果页查看模型实际生成的文件、版本和测试结果，在右侧预览阅读或另存原件。普通聊天显示可读回答，原始运行协议放在高级详情。

工作任务需要修改时先记录返工意见，再明确点击“执行返工”；只有这一步才开始新运行。检查新版后按该交付版本验收。输入区显示“仅记录”时只保存内容，不会隐式执行返工。

## 失败与恢复

失败原因在对应操作附近显示；先保留输入和原件，再按提示明确重试。结果未知与明确失败不同：未知操作保留原信封，只有你确认后才人工同号同参重放；重连、重开不会自动重发、继续任务或解除保护。

需要排查时打开“设置 → 帮助与关于 → 查看诊断 / 复制诊断”。默认复制脱敏状态，不上传数据库、正文、图片或账号密钥。

版本工程验收与用户确认分开；以本包交付记录中的实际通过项和剩余门为准。Android、安装器、签名、自动更新及自动分工不在本版范围内。
