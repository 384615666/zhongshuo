## 1. 设计原则

1. **桌面工具，不是营销页**：效率优先，装饰最少。不用渐变背景、不用大面积阴影、不用插画式空态。
2. **密度来自布局，不来自小字号**：密度靠稳定的三栏结构与行距效率获得；正文字号保持阅读舒适（§3、§5.8），禁止用 12px 以下的字号塞内容。
3. **面差分层优于描边**：容器分层优先用背景色阶（`--bg-app` → `--bg-surface` → `--bg-surface-2`），描边只留给必须划清边界的场景（§4.4）。满屏 1px 线框是视觉疲劳的主要来源。
4. **双主色，一屏一个焦点**：清透蓝 `--accent` 为主、薄荷绿 `--accent2` 为辅（success 族）；同一视图内着语义色的元素 ≤ 2 处，其余用中性灰。紫、青、琥珀只用于成员身份识别。
5. **层级靠字重和灰度，不靠颜色**：标题/正文/辅助/弱提示四级文字灰度递进，彩色只留给可操作元素和状态。
6. **状态必须"文字 + 图标"成对出现**（§17.5），颜色永远只是第三重冗余。
7. **4px 基准栅格 + 圆角克制**：间距只用 `--sp-1`～`--sp-5`；气泡/卡片 12px、控件 8px、小元素 6px，胶囊仅用于标签/徽标。

## 3. 字体与排版

| 令牌 | 值 | 用途 |
|---|---|---|
| `--font` | Segoe UI / Microsoft YaHei UI 栈 | 全局 |
| `--font-mono` | Cascadia Mono / Consolas / Sarasa Mono SC | 代码、任务号、ID |

字号刻度（共 8 档，按密度档位使用，见 §5.8）：

| 令牌 | 大小 | 用途 |
|---|---|---|
| `--fs-11` | 11px | 徽标数字、极弱提示 |
| `--fs-12` | 12px | 标签、时间戳、元信息（**不作正文**） |
| `--fs-13` | 13px | 紧凑档正文基准；舒适档的次级文字 |
| `--fs-14` | 14px | 卡片标题、房间名、次级正文 |
| `--fs-15` | 15px | **主阅读正文**（回复串消息、报告）；面板标题 |
| `--fs-17` | 17px | 页面标题 |
| `--fs-20` / `--fs-24` | 20/24px | 仅空态/引导页 |

字重：正文 400，强调 650（`.strong`），标签/标题 600–650。**不使用 300 以下的细字重**（Windows 上发虚）。
行高：正文 1.6（长文阅读 1.65），标题 1.3，单行控件 1。

**阅读宽度**：消息正文行宽上限 68–76 字符（约 640–720px）。对话列更宽时，气泡内容居左限宽、剩余空间留白，不拉伸文字行；报告/文档页正文同样限宽。

## 4. 间距、圆角、阴影

### 4.1 间距（4px 基准）

`--sp-1: 4` `--sp-2: 8` `--sp-3: 12` `--sp-4: 16` `--sp-5: 24`

- 图标与文字之间：`--sp-1`
- 控件内部 padding：`--sp-1` × `--sp-2`（紧凑）或 `--sp-2` × `--sp-3`（常规）
- 卡片内边距：`--sp-4`（16px）为默认；仅表格行、密集列表可用 `--sp-3`
- 卡片之间、区块之间：`--sp-3`（紧凑档）/ `--sp-4`（舒适档）
- 大区块分隔：`--sp-5`

### 4.2 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `--r-xs` | 4px | 代码片、kbd |
| `--r-sm` | 8px | 小徽标、聚焦环 |
| `--r-md` | 10px | 输入框、下拉、内嵌块 |
| `--r-lg` | 16px | **消息气泡、卡片（主档位）** |
| `--r-xl` | 20px | 输入区、弹层、覆盖面板 |
| `--r-full` | 999px | 头像、徽标、计数 chip（按钮/页签/导航行用 r-md/r-sm，v1.5 取消全面胶囊化） |

### 4.3 阴影（三级，静态卡片不用阴影）

| 令牌 | 用途 |
|---|---|
| `--shadow-sm` | 输入框外唯一允许的静态阴影（可省） |
| `--shadow-md` | 下拉菜单、悬浮卡片 |
| `--shadow-lg` | 模态、覆盖式详情面板 |
| `--ring` / `--ring-danger` | 聚焦环 / 危险聚焦环 |

**阴影只表达"浮起来了"**：下拉、popover、覆盖面板等浮层用 `--shadow-md/lg`；静态内容不靠阴影撑层次（分层手段见 §4.4）。

### 4.4 描边使用规则（面差优先，v1.1 新增）

容器分层的第一手段是**背景色阶**，不是描边：

1. 卡片/面板放在 `--bg-app` 上时用 `--bg-surface` 底 + **1px `--border-subtle` 轻描边或不描边**——二选一的判据：父底与面板亮度差 < ~8% 时**必须选轻描边**（如 `--bg-app #eef0f4` vs 白面仅 ~5%，不描边会"化开"）；
2. 只有三种情况必须用 `--border` 描边：浮层（下拉、popover、toast）、与父容器同为 `--bg-surface` 的嵌套容器、可点击卡片的可点边界提示；
3. **卡片内部元素禁止再描边**：卡内分隔用 `--border-subtle` 1px 横线或 `--sp-3` 留白，内嵌块用底色差（§5.2）；
4. 输入框等交互控件仍用 `--border-strong`，保证可发现性；
5. 一页截图里肉眼可见的描边矩形应 ≤ 5 个，超出即视为返工信号。

## 5. 核心组件规格

### 5.1 消息气泡

- 容器：`--bg-surface` 底、`--r-lg` 圆角、内边距 `--sp-4`；描边按 §4.4（轻描边或不描边）。
- 用户（人类）气泡可用 `--accent-soft` 底 + `--accent-border` 描边以区分"我说的"；agent 气泡一律中性白底，靠作者头像色区分归属。
- 选中/活跃线程：左侧 2px `--accent` 竖条 + `--bg-selected` 底，**不加粗描边、不换大阴影**。
- 作者行：头像 20–24px（`--r-sm`）+ 名字（`--fs-13` 650 重）+ 时间戳（`--fs-12`，`--text-4`，右对齐）。
- 相邻同作者消息间距 `--sp-1`，跨作者 `--sp-3`。

### 5.2 任务卡 / 系统卡 / 提示条

- 卡片 = 气泡容器规格 + 标题行（`--fs-14` 650 重）。
- **嵌套上限 2 层**：卡片内最多再嵌一层内容块；内嵌块用 `--bg-sunken` / `--bg-surface-2` 无底边、`--r-md`，形成"面-底"对比而不是"边框套边框"。需要第三层时，改为"展开"链接或跳转详情页。
- 长内容（agent 报告、验证记录）默认折叠到 3 行 + "展开全部"，不在主池撑高。
- 警示条（如"有任务正在改文件"）：`--warning` 三件套（soft 底 + border 描边 + 主值图标/文字），不闪烁、不自动消失。

### 5.3 标签（pill / 状态章）

- 高度 20px、`--r-full`、字号 `--fs-12`、横向 padding `--sp-2`。
- 着色标签（执行中/待审阅/只分析）：语义色三件套（主值文字 + `-soft` 底 + `-border` 描边）。
- 无状态标签（#14、讨论）：`--neutral` 三件套。
- **着色标签配额**：同一消息卡上着语义色的标签 ≤ 2 个，其余一律 neutral；任务号、房间名、成员名永远 neutral，不因为"可点击"就上主色。
- 状态点 6px 圆点 + 文字，缺一不可（§17.5）。

### 5.4 按钮

| 类型 | 规格 |
|---|---|
| 主按钮 | `--accent-grad` 渐变底（端点压深保证白字可读；深色下用深字）、`--r-md`、主色投影；禁用降透明度到 0.5 |
| 次按钮 | `--bg-surface` 底 + `--border-strong` 描边 + `--text` 字 |
| 幽灵按钮 | 无底无框，hover 出 `--bg-hover` |
| 危险按钮 | `--danger` 底白字；低危警示操作用 danger 幽灵按钮 |

高度：常规 32px，紧凑（顶栏/工具栏）28px。图标按钮正方形。

### 5.5 输入区（composer）

- 外框 `--border-strong`，聚焦时描边变 `--accent` + `--ring` 聚焦环。
- 工具栏与输入框同属一个 `--r-lg` 容器，内部分隔用 `--border-subtle` 1px 横线。
- 目标标签（"→ 子任务 #n"）用 `--accent` 三件套胶囊，放在输入框上沿。

### 5.6 侧栏 / 顶栏

- 侧栏：`--bg-surface` 底，当前项 `--bg-selected` + 左侧 2px `--accent` 竖条；未读数字用 `--accent` 胶囊徽标，超过 99 显示 99+。
- 顶栏：高 46px、`--bg-surface` + 底部 1px `--border`；统计入口（后台任务、恢复检查）用幽灵按钮，告警数量用 `--warning` 徽标。

### 5.7 头像

- 圆形（`--r-full`，v1.4 起），字母缩写居中，底色 = 成员识别色，白字。
- 尺寸档：消息内 24px、列表 20px、详情 32px。

### 5.8 密度档位（v1.1 新增）

| 维度 | 舒适档（默认） | 紧凑档 |
|---|---|---|
| 正文字号 | `--fs-15` | `--fs-13` |
| 消息行高 | 1.65 | 1.55 |
| 卡片内边距 | `--sp-4`/`--sp-5`（上下/左右） | `--sp-3` |
| 列表行高 | 36px | 30px |
| 卡片间距 | `--sp-4` | `--sp-3` |

- 档位是应用级偏好（设置页切换，跟随 `--font`/密度类令牌整组切换），组件不写死档内数字。
- 舒适档面向阅读与审阅场景（看报告、回帖）；紧凑档面向多任务监控场景。默认**舒适档**。

### 5.9 现代化形态约定（v1.2 新增）

针对"令牌收敛了但造型偏老"的问题，以下形态规则优先于旧版描述：

1. **页签 = 分段控件**：灰槽（`--bg-surface-3`，padding 2–3px，`--r-md`）内嵌选项（高 26px，`--r-sm`，`--fs-12`），激活项白底 + `--shadow-sm` 浮起；不再使用下划线指示。
2. **标签 = 图标 + 着色文字**：无底色、无描边、无圆角壳；颜色取语义色主值（`--accent-text` / `--warning` / `--text-3`）。任务号（#14）用 `--font-mono` + `--text-3`，无任何容器。胶囊壳只保留给：数字徽标（未读数）、未读计数 chip。
3. **警示条去描边**：`soft` 底 + 左侧 2px 语义竖条（`box-shadow: inset 2px 0 0`），不再画完整边框。
4. **面板关系用"通高列 + 发丝线"**：侧栏、回复串等常驻面板直接通高，用 1px `--border-subtle` 分隔；不要做成悬浮圆角盒子。
5. **输入区是唯一轻浮起的静态容器**：`--r-xl` + `--shadow-sm`，聚焦时描边变主色 + `--ring`。

## 6. 深色主题

- 通过 `:root[data-theme='dark']` 整组切换令牌（见 tokens.css），组件不感知主题。
- 深色下 `-soft` 底色改为带透明度的色板（如 `rgba(96,152,255,.14)`），避免深色面上出现"亮色块"。
- 深色阴影加深但面积不变；聚焦环透明度提高（`--ring` 0.22 → 0.30）。

## 7. 禁止清单（Do / Don't）

| ❌ 禁止 | ✅ 替代 |
|---|---|
| 在组件里写 `#2563eb` 这类裸色值 | 用令牌；确需新值先加进 tokens.css 并在本文件登记 |
| 5/6/7/9px 间距 | 收敛到 `--sp-*` |
| 卡片叠阴影 + 描边 + 底色三层 | 静态卡片只用描边 |
| 给状态换颜色但不改文字 | 状态 = 图标 + 文字，颜色第三 |
| 用成员色做按钮/背景块 | 成员色只在头像和归属条 |
| 新增第九档字号 | 用现有 8 档，靠字重分层级 |
| 蓝色表达"信息"以外的含义 | 警告黄、成功绿、危险红各就各位 |
| 为美观隐藏滚动条/弱化禁用态 | 滚动条 10px 常显；禁用 = 透明度 0.5 + `not-allowed` |

## 8. 验收清单（改样式后自查）

1. `base.css` / `components.css` 中无新增十六进制色值（`git diff -U0 | grep -E '#[0-9a-fA-F]{3,8}'` 应为空，tokens.css 除外）。
2. 无新增非 `--sp-*` 的 px 间距、无新增非 `--r-*` 的圆角。
3. 每个状态同时有文字与图标。
4. 浅色/深色各截一张图，确认 `-soft` 底、描边、文字对比在两套主题下都成立。
5. 键盘 Tab 走一遍主流程，每个可聚焦元素都有可见聚焦环。
6. 200% 缩放下布局不破、不横向滚动。
7. 任一截图内描边矩形 ≤ 5 个；卡片嵌套 ≤ 2 层，卡片内部无描边子容器（§4.4、§5.2）。
8. 单视图内着语义色元素 ≤ 2 处；正文行宽 ≤ 76 字符（§3、§5.3）。
9. 舒适档下正文为 `--fs-14`，无 12px 以下的阅读性文字（§5.8）。
