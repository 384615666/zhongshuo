# 众说 0.1.2

0.1.2 修复 Windows 任务栏与文件属性仍显示 Electron 的问题，并把上一版（0.1.1）的 logo/界面清理一并包含。不改变任务执行、数据格式与安装位置，可直接覆盖安装。

- **重写随包 EXE 版本信息**：`Zhongshuo.exe` 的 PE 版本资源不再沿用 Electron 的默认描述，ProductName、FileDescription、InternalName、OriginalFilename、公司、版权与文件版本统一为「众说」。构建时使用 Win32 资源 API 写入 en-US / zh-CN 两份 Unicode 字符串表，并在独立进程回读 `FileVersionInfo` 校验，任何一项不符即中止出包。
- **任务栏身份隔离**：安装版改用新的稳定 AppUserModelID `com.zhongshuo.desktop.app`，安装器快捷方式同步；便携/开发版使用 `com.zhongshuo.desktop.portable`。旧的 Electron 名称/图标缓存只属于旧 AUMID，新版任务栏会显示「众说」与正式猫咪 logo，不再与旧 V78/旧安装版合并成一个按钮。
- 任务栏、文件属性、未来 Shell 分组不再显示 `Electron`；桌面/开始菜单快捷方式、窗口图标、原生 EXE 图标继续使用正式猫咪 logo（0.1.1 已具备）。
- 0.1.1 的界面修复同时包含：正式 logo 覆盖欢迎页/窗口/数据操作页、清理开发说明文字、新品牌安装向导与更新后的操作手册截图。

安装 `Zhongshuo-Setup-0.1.2-x64.exe`，无需管理员权限。升级前请正常退出众说；可直接覆盖 0.1.0/0.1.1/beta 版本，聊天、项目、成员与设置保留。卸载保留用户数据。

本版本不修改 AppId、安装目录或数据目录；未做 Authenticode 签名，Windows 可能显示未知发布者。随 Release 提供 SHA256 校验文件与构建元数据。
