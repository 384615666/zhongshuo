# 众说 1.0.0

众说 1.0 正式发布。这是 Windows 本地多 Agent 协作工作台，把本地文件夹当作项目，让 Claude Code、Codex、DeepSeek Harness、Pi 等 AI 成员在同一项目/房间里分工、讨论、执行、互相核对；对话、文件与成果保存在本机，模型请求经你配置的渠道发出。

## 1.0 内容

- **正式版本号**：`package.json` / 安装器版本统一为 `1.0.0`（Windows 文件版本 `1.0.0.65535`）。
- **设置页收尾**：按用户反馈，设置页已去掉页头/分区说明、设置行内小字、草稿设置，以及「当前显示」「已开启」「当前上限」等状态文字；「我的头像」的上传/恢复按钮组改为靠右对齐；紧凑重排后行高约 46px、标签与控件垂直居中，分区之间保留 18px 间距。
- **版本名称**：设置 → 帮助与关于显示「众说 · 本地多Agent协作工作台」。
- **README**：已更新为 1.0 版本（下载安装包入口、快速开始、状态徽章、页脚），并给出 GitHub Release 的安装包与 SHA256 链接。
- **产品主页 `site/index.html`**：首屏改为「1.0 正式版」，主按钮改为下载 Windows 安装包；「开始使用」改为下载优先、源码构建作为备选；页脚更新为 1.0 已发布；`site/README.md` 的文案边界同步更新。
- 功能、数据格式与 schema（61）不变；1.0 是已发布 beta 的功能收尾与正式发行，升级保留项目、聊天、附件、任务与草稿。

## 安装包

- 文件：`Zhongshuo-Setup-1.0.0-x64.exe`
- 大小：`PENDING_BYTES` 字节；SHA256：`PENDING_SHA`
- 构建：干净 worktree `dist/r208-source`（`PENDING_COMMIT`，status 0，`dirty=false`），便携镜像 BUILD `PENDING_BUILD1`（clean、`PENDING_FILES1` 文件 MANIFEST 逐项 SHA256 复核），安装器 BUILD `PENDING_BUILD2`（安装镜像 `PENDING_FILES2` 文件 MANIFEST 逐项 SHA256 复核；payload-audit `files=PENDING_FILES2`、`runAsNode=false`、`privacyScanPassed=true`、`dataFilesIncluded=false`）
- 未签名，仅支持当前 Windows 用户安装（无需管理员），SmartScreen 可能提示「未知发布者」。
- 升级/卸载前请先在系统托盘正常退出众说；升级不删除已有聊天、项目与草稿数据。
- 本机未安装/升级/卸载，未操作用户运行数据。
