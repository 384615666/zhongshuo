# 众说 1.0.2

本版修复 Windows 安装时的 DeepSeek Harness 连接组件配置，以及 Claude 的代理识别与安装完整性提示。数据格式与 schema（61）不变。

## 更新

- **Harness 连接组件在安装时自动配置**：支持 PATH 中 `dsh.cmd` 再转发到官方入口的情况；默认入口无法识别时检查常规安装位置。组件内容一致时只检查就绪状态，不重复安装。已有渠道、MCP 与会话配置不由众说覆盖。
- **修正 Claude 代理误报**：合法 HTTP/HTTPS 代理不再仅因存在就被判为“改变渠道或宿主执行”；代理仍原样传递，已有配置变更检查继续生效。
- **不绕过代理查询模型列表**：代理场景保留本机已配置的模型，也可手动填写。实际模型连接由 Claude CLI 自身处理；本版未新增通过代理读取远端模型清单的功能。
- **明确提示 Claude 安装不完整**：识别官方 npm 包中“原生程序未安装”的占位脚本，不再把它当作可运行程序。众说不会代装或修复 Claude Code；如遇该提示，请先修复官方 CLI，再重新扫描成员。
- 版本号 `1.0.2`，Windows 文件版本 `1.0.2.65535`。

## 安装与边界

- 仅提供 Windows x64 当前用户安装包，不提供便携版。
- 更新前请先从系统托盘正常退出众说，再自行运行新版安装包。
- 不自动迁移数据，不覆盖第三方 CLI 的凭据或默认配置，不代装第三方 CLI 本体。
- HTTP/HTTPS 代理支持不等于已验证代理连通性、登录状态或模型可用性；ALL_PROXY 保留透传，不对其官方支持或生效作认证。
- 安装包未签名，Windows SmartScreen 可能显示“未知发布者”。
