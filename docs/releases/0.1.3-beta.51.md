# 众说 0.1.3-beta.51

本版继续按用户 2026-11-08 反馈精简设置页：上一版去掉了页头/分区小字，这一版把**设置行内的小字说明**也全部去掉（「浅色、深色随时切换」「默认显示个人和 AI 头像，姓名始终保留」「聊天里你自己那一侧显示这张；AI 成员头像在成员管理里设置」等）。功能与数据格式不变，schema 仍为 61，升级保留项目、聊天、附件、任务与草稿。

## 改动

- **设置行内说明全部移除**：
  - 外观：主题、显示头像、我的头像、我的名字（含头像选择器下方的 PNG/JPEG/大小提示）；
  - 通知：允许弹出系统通知；
  - AI 设置：启用调用次数预算（默认上限小字）、同时运行的 AI（三项上限说明与执行规则说明）；
  - 数据与存储：备份、恢复、清理存储、归档管理、已移除的项目；
  - 帮助与关于：操作手册/GitHub/产品主页入口的链接说明、本机诊断的「只在本机读取…」说明。
- **保留功能性信息**：当前状态/结果/错误（如「当前显示「你」」「已开启」「当前上限：全局 4…」「共 0 个项目」「已释放 X 兆字节」「保存失败…」）仍显示，它们不是装饰性文案；设置行 hint、分区说明、页头说明已全部不渲染。
- 机器可读属性保持：`data-zs-call-budget-defaults` 从可见小字移到外层容器属性，数值不变；其它 `data-zs-*` 验收钩子不受影响。
- 草稿设置的移除保持上一版结果（无草稿分组/状态/清理入口；「清理存储」保留在数据位置与备份分组）。
- 未改设置行基元、其它页面、数据与命令。
