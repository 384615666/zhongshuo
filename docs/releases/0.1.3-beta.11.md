# 众说 0.1.3-beta.11

测试版，修复项目归档与私信显示，并统一项目切换交互。

- 项目里已停止且没有后续排队请求的失败记录可以保留归档；排队、执行或等待处理的任务仍须先结束。失败记录与已有聊天保留。
- 私信列表使用正确的成员头像，与消息区一致。
- 已在当前私信中时，不再提示「打开私信」。
- 普通私信回复完成后隐藏完成横幅；需要验收时继续保留处理入口。
- 点击项目名称切换项目，在私信、成员管理页保留页面类型；项目名称前的小箭头只展开、收起房间列表。

升级前请先从托盘选择「退出众说」。升级保留聊天和项目文件，数据结构仍为 61，不自动导入或搬迁数据。

Windows 数字版本为 `0.1.3.11`。
