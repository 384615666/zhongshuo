# 众说 0.1.3-beta.15

测试版，精修设置页排版、统一主区底色，并修掉开始菜单里显示成 Electron 的问题。

- **开始菜单名字**：安装器会清理早期未品牌化版本留下的 `Electron` / `ElectronApp` 快捷方式（只在它确实指向众说时才删），开始菜单与搜索里不再出现这两个名字。
- **背景色统一**：私信页原来透出窗口底色（浅蓝 `#F2F8FB`），现在与房间、回复串一样是白色主区；三处主区底色一致。
- **设置页排版精修**：每个分区按卡片分组（启动 / 显示 / 我的头像 / 桌面通知 / 对话串通知 / 投递记录 / 调用次数预算 / 同时运行的 AI / AI 成员 / 数据位置与备份 / 草稿 / 归档与项目 / 手册与项目链接 / 版本）；开关与按钮统一右对齐；「桌面通知」不再重复出现两次；投递记录收进折叠区；标题与搜索吸顶，滚到任何一段都能直接搜索；搜索结果是浮层，不再把下面的内容顶下去。
- **标题栏设计提案**（不开发）：`docs/design-proposals/titlebar-r158.md` 给出顶部区域三层叠加的实测数据、三个可选方案与验收标准，等你选。

本版包含此前 beta.11–beta.14 已合入的私信分组、渠道头像、房间/私信置顶与渐进式会话列表。

安装前请从系统托盘右键选择 **退出众说**，等待程序退出后运行 `Zhongshuo-Setup-0.1.3-beta.15-x64.exe`。右上角 **×** 只隐藏窗口；安装器不会自动关闭运行中的众说。升级保留聊天与项目文件，数据结构仍为 61。

Windows 数字版本为 `0.1.3.15`。
