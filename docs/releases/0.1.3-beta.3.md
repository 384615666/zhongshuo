# 众说 0.1.3-beta.3

本地候选版，修复协作交接与恢复诊断问题。

- 并行生成文件时，交接清单区分各成员成果与共享目录观察，避免汇总步骤误报同名文件冲突。已有交接记录保持原样，继续任务时按原始成果依据核验。
- 同一协作中的合法修订可以作为后续步骤的新文件版本，外部改动和没有依赖关系的冲突仍会阻止派发。
- 执行失败展示具体原因，任务详情列出未能启动的成员任务。
- 保存正常停机的逐轮核查依据，避免被后续空停机覆盖。结果未知的任务仍须核查，不会自动成功或重新执行；旧版已丢失的证据无法补造。

先从系统托盘退出众说，再运行 `Zhongshuo-Setup-0.1.3-beta.3-x64.exe` 覆盖安装。运行中会阻止安装，需要用户先退出。聊天与项目文件保留，数据结构仍为 61。本次未发布到 GitHub，安装包未签名。
