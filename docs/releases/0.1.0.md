# 众说 0.1.0

Windows 本地多 AI 协作工作台的首个正式发布版本。

- 在项目房间和回复串中使用 Claude Code、Codex、DeepSeek Harness、Pi，支持指定成员、自动协作、共同研讨及私信。
- 首次打开、打开项目和新建房间时发现已安装的 CLI，成员页可重新扫描。新安装后可发现；卸载后保留成员配置与历史，缺程序的新请求会在入队前拒绝；重装复用原成员。
- 项目文件预览、交付与验收、任务停止与恢复、数据备份等入口随包提供离线操作手册。
- Windows 安装器、原生 EXE、桌面快捷方式及任务栏统一采用新 logo。

安装 `Zhongshuo-Setup-0.1.0-x64.exe`，无需管理员权限。升级前请正常退出众说；可直接覆盖 beta 版本，保留聊天、项目与设置。卸载保留用户数据。

AI CLI 及模型渠道需要自行安装、登录和配置。Claude/Codex 自动添加需要可识别的默认模型；DeepSeek Harness 还需要随包的众说连接组件。众说不捆绑 API 密钥或模型额度。

此版本安装包未做 Authenticode 签名，Windows 可能显示未知发布者。随 Release 提供 SHA256 校验文件和构建元数据。
