# 众说 0.1.3-beta.33（候选）

本候选在 `0.1.3-beta.32` 候选的源码基线上，加入 2026-11-07 反馈的八项界面修复；`beta.30–beta.32` 的读取超时、Harness 组件升级等改动由并行开发流提供（详见其记录），本文件只列界面部分。

## 成员管理 / 任务看板 / 文件与 Git / 搜索与收藏

- 左侧项目卡列的左右留白统一收到 16px 且左右相等（此前左侧 24/40px、右侧 8px）；成员管理、任务看板、文件与 Git、搜索与收藏四页一致。
- 侧栏「项目 / 房间」拖动排序：平时不再显示抓取光标，只有真正拖动时才变成抓取样式；拖动顺序仍按本机保存。
- 任务看板：卡片右上角归档按钮由 × 改为 √，提示改为「归档」；去掉筛选行里的「房间」下拉，看板固定显示当前范围全部房间（旧链接里的房间筛选参数会被自动清理，不再弹提示）。
- 文件与 Git：顶部项目下拉换成左侧项目卡片列；点项目卡会切换到对应项目的文件页（当前文件/Git 页签保留），切换时界面不再向左位移。
- 搜索与收藏：左侧也换成项目卡片列，替换原来的「范围」下拉；「全部项目」卡代表侧栏当前可见项目，点具体项目卡会同时把当前项目切过去。
- 文件与 Git 页不再显示「此文件夹未初始化 Git」提示；普通目录的文件树与预览照常。

本候选使用隔离数据与模拟执行验证，没有调用真实模型；数据库格式保持 schema61。

仅交付 Windows 安装包。请先在系统托盘退出众说，再由你自行安装更新；安装/升级不删除已有聊天与项目数据。
