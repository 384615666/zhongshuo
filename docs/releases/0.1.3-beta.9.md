# 众说 0.1.3-beta.9

测试版，简化中断任务的恢复操作。

- 没有待恢复事项时，左下角自动隐藏“恢复任务”；正常排队不会显示恢复提醒。
- 恢复弹窗提供 **一键继续**，批量继续中断任务及等待恢复的排队消息。同一任务的多个协作中断会合并处理。
- 提交成功后自动关闭弹窗，已处理事项从恢复列表移除；没有剩余事项时，入口自动隐藏。任务会在后台继续。
- 部分失败会保留具体原因，重试只处理剩余事项。聊天、文件与任务历史保留。
- 未完成的撤销会在任务继续前先处理；遇到文件冲突时显示提示，供核对后重试。

本版保留此前已合入源码的预设头像、成员模板头像、宽屏布局及托盘 AI 工作量面板。

安装前请从系统托盘右键选择 **退出众说**，等待程序退出后运行 `Zhongshuo-Setup-0.1.3-beta.9-x64.exe`。右上角 **×** 只隐藏窗口；安装器不会自动关闭运行中的众说。升级保留聊天与项目文件，数据结构仍为 61。

Windows 数字版本为 `0.1.3.9`。
