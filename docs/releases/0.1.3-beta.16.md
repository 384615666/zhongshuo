# 众说 0.1.3-beta.16

测试版，补齐开始菜单名字的自愈，并包含 beta.15 的设置页精修与主区底色统一。**请直接装这一版**（beta.15 已由本版取代）。

- **开始菜单名字（本轮重点）**：
  - 安装版每次启动会清掉早期未品牌化构建留下的 `Electron` / `ElectronApp` 快捷方式——只在快捷方式里确实写着本程序 exe 名时才删，窗口出现后 4 秒再复查一次。
  - 窗口身份注册补上 `relaunchCommand`：只给显示名时 Windows 拿不到完整注册，会按默认身份（ElectronApp）在开始菜单生成一条快捷方式，这正是「装完名字还是不对」的来源。
  - 安装器同样会在安装后清理（目标必须等于 `{app}\Zhongshuo.exe` 才删，不碰其它软件的同名项）。
- **背景色统一**（beta.15 起）：私信页原来透出窗口底色（浅蓝 `#F2F8FB`），现在与房间、回复串一样是白色主区。
- **设置页排版精修**（beta.15 起）：每个分区按卡片分组；开关与按钮统一右对齐；「桌面通知」不再重复；投递记录收进折叠区；标题与搜索吸顶，滚到任何一段都能直接搜索；搜索结果是浮层，不再把下面的内容顶下去。
- **标题栏设计提案**（不开发）：`docs/design-proposals/titlebar-r158.md` 给出顶部三层叠加的实测数据、A/B/C 三个方案与验收标准，等你选。

本版包含 beta.11–beta.14 已合入的私信分组、渠道头像、房间/私信置顶与渐进式会话列表。

安装前请从系统托盘右键选择 **退出众说**，等待程序退出后运行 `Zhongshuo-Setup-0.1.3-beta.16-x64.exe`。右上角 **×** 只隐藏窗口；安装器不会自动关闭运行中的众说。升级保留聊天与项目文件，数据结构仍为 61。

Windows 数字版本为 `0.1.3.16`。
