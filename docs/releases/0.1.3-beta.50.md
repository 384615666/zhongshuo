# 众说 0.1.3-beta.50

本版按用户 2026-11-08 反馈精简设置页：去掉页头与各分区的小字说明，并去掉草稿相关设置。功能与数据格式不变，schema 仍为 61，升级保留项目、聊天、附件、任务与草稿。

## 改动

- **去掉设置页小字文案**：
  - 页头「外观、通知、AI、数据与帮助都在这一页；改动会即时保存并回读确认。」删除；
  - 五个分区的说明行全部删除：「主题、头像和名字；只在本机生效。」「桌面通知总开关。」「调用预算与同时运行的 AI。」「数据位置、备份、草稿与归档。」「手册、链接、版本与诊断。」；
  - 现在每张卡片只保留分区标题 + 设置行；设置行自身的控件说明（如「浅色、深色随时切换」）保留，因为它们是每个选项的解释，不属于装饰性小字。
- **去掉草稿设置**：
  - 删除「草稿」分组的「草稿保存」状态行、「重试 / 清理」行（重试保存、清理本地草稿）、草稿恢复提示与清理确认弹窗；
  - 「清理存储」（回收变更前像与过期回执正文，不是草稿）保留，并移到「数据位置与备份」分组，功能不变；
  - 设置搜索索引同步：删除「草稿保存与重试」「清理本地草稿」两个条目，新增「清理存储」条目；
  - 草稿在后端仍按原逻辑保存与恢复（输入、发送、崩溃恢复不受影响），只是不再在设置页展示草稿状态/清理入口。
- 未改设置行基元、其它分区设置、数据与命令。
