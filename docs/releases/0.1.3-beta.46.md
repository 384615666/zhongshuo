# 众说 0.1.3-beta.46

本版按用户 2026-11-08 新一轮 6 条界面反馈修复。功能、数据格式与 schema（61）不变，升级保留项目、聊天、附件、任务与草稿。

## 6 条反馈与修复

1. **「打开新的工作区」按钮选中/hover 底色位置不对**：按钮此前继承了通用 `button` 的 6px/12px 内边距——20px 的盒子被 padding 撑成 24px 宽，图标被挤到右侧、hover 底色与图标错位。现在显式 `padding: 0`、锁定 20×20，hover 底色与图标同心（截图 `dist/r201-ui/r201-v4/02-workspace-hover.png`）。
2. **工作区按钮 tooltip 太长**：title/aria-label 统一改成「打开新的工作区」，不再解释切换/保留规则。
3. **去掉顶部「众说」旁的切换工作区组件**：标题栏不再有「当前项目 ▾」项目下拉（项目切换走侧栏「工作区」按钮与项目列表；打开工作区本身仍保留）；标题栏只剩品名、异常连接状态与窗口按钮。
4. **去掉搜索里的「退出键」和「回车键」提示与按钮**：命令面板（Ctrl+K）删除右上角「退出键」按钮、选中行「回车键」标签，搜索框 placeholder 也不再写键盘提示；上下键/回车/Esc 的键盘行为保留。
5. **「最近活动 X 秒前」不再换行**：活动行改为单行——长命令/目标文本省略号截断，「最近活动 X 秒前」固定尾部、不换行也不撑高卡片（截图 `07-live-progress.png`）。
6. **`file:///` 本地文件链接只显示文件名**：AI 回复里的 `![图](file:///C:/...)` / `[文件](file:///...)` 不再露出原始地址或当成外链，改为文件图标 + 文件名；左键用默认程序打开，右键菜单提供 **复制文件地址 / 用默认程序打开 / 在文件管理器中显示**（以及检测到的其它打开方式），与消息下方本机文件卡的操作一致。只解析明确的 `file:` 绝对路径（Windows 盘符/UNC/百分号编码），http(s)/mailto/相对路径仍按普通链接处理。
