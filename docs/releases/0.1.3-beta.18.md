# 众说 0.1.3-beta.18

测试版。本版把房间页的两条顶部栏合并成一条，内容区多出一截；同时包含上一版（beta.17）的通知与私信修复。

## 本版改动

- **房间顶部合并成一行**：原来「房间名 + 成员 + ⋯」一行、「对话池 / 任务看板 / 文件」又一行，共约 118px；现在合成一条 42px：
  `对话池 任务看板 文件 ……… 3 条未读 ｜ Claude · 2 名成员`
- **房间名不再单独占一行**：侧栏里当前房间已经是高亮状态（带未读圆点），窗口栏仍显示项目名。
- **房间 ⋯ 去掉**：房间设置、成员、归档都在「点成员入口」打开的房间设置里，操作没有减少。
- **成员入口移到最右**：右端依次是「未读数 → 成员」。
- **窄窗自动收**：宽度 ≤960 时隐藏未读标签、页签内边距收紧，不横向溢出（1360 / 1100 / 900 三档实测 `scrollWidth == clientWidth`）。

本版只动房间页顶部这一处；窗口栏、侧栏、设置页、对话串与私信布局都没有改。

## 同时包含 beta.17 的修复（上一版只出包、未发布 Release）

- Windows 通知来源身份注册（通知标题不再显示错误来源）
- 私信未读数改为仅圆形徽标；本人消息不计未读；窗口回到前台后自动已读
- 跨项目展示总数超过 20 后的「5 条 / +10」折叠，与房间执行投影、侧栏刷新相互独立

安装前请从系统托盘右键选择 **退出众说**，等待程序退出后运行 `Zhongshuo-Setup-0.1.3-beta.18-x64.exe`。右上角 **×** 只隐藏窗口；安装器不会自动关闭运行中的众说。升级保留聊天与项目文件，数据结构仍为 61。

Windows 数字版本为 `0.1.3.18`。
