# 众说 0.1.3-beta.1

本地候选安装包，集中处理托盘、任务分工、附件交接和设置界面的九项反馈。

- 点击右上角关闭按钮后隐藏到系统托盘，任务继续运行；单击托盘或再次打开程序可恢复窗口。托盘右键提供打开众说、设置、操作手册、数据目录和退出入口，退出会先关闭后台服务。
- DeepSeek Harness 连接组件升级到 0.1.3，安装归档保存在 DSH 自有组件目录，模型读取使用更长的等待窗口。模型在 DSH 的 `zhongshuo` 配置中设置，`dsh web` 的配置独立。
- 协调者先提交分工，把自己的实施工作列为子任务；独立步骤一起进入执行队列，按依赖、并发额度及文件写入策略启动。
- 交接生成的 Word、Excel、PPT、PDF 时自动补建缺失的提取缓存，无需先手动预览；原文件损坏、变化或超出范围时仍停止派发。
- 项目设置 → 文件修改 → 同时修改文件的任务，新增“跨对话串并行（默认）”“单写者”“允许成员并行”。并行仅适用于完整权限的不同成员；运行中或存在未解除保护的任务时不能更改。
- 修复深色主题顶部栏，统一操作手册与其他设置页的导航位置，移除图片发送的常驻提示，保留实际错误提示。

升级前请正常退出旧版，再安装 `Zhongshuo-Setup-0.1.3-beta.1-x64.exe`。安装位置和数据目录沿用旧版，数据结构升级至 61；安装、升级与卸载保留聊天和用户文件。安装包未签名，本次未发布到 GitHub。
