# 众说 0.1.3-beta.41

本版是一次后端审计修复 + 一次性收口：修复「较晚请求的附件会提前进入前一个请求的模型输入」和「停止后继续会换成员/扩大研讨名单」两项后端缺陷；同时把仓库里此前一直未提交的侧栏「工作区」改动（标题固定、打开/切换按钮上移）一并纳入，版本继续包含 beta.40 的九项界面改进。功能合同、数据格式与 schema（61）不变，升级保留项目、聊天、附件、任务与草稿。

## 主要改动

- **请求材料边界（审计项 2）**：每次派发按「接受这条请求时」的固定线程序号装配历史与附件，不再读取实时串尾；DELIBERATE 各阶段读取自身请求的 `input_thread_seq`。后续排队请求的文字/图片/文件不会提前进入前一个请求的模型输入；当前请求自己的材料仍完整发送。提醒派发按完整派发键绑定当前唤醒消息与序号；协作子任务通过协调运行的正式附件来源保留规划/交接详情。
- **停止后继续保留原成员与模式（审计项 3）**：停止后的「继续任务」与不重新指定成员的普通续接，会沿用最后一次实际执行的线程请求、路由、成员与研讨子集，不再回退根任务负责人或扩成当前全名单；不会执行未执行的后续排队请求。原成员停用/移出时原子拒绝并回滚，用户可显式重新选择 AI；新派发仍使用新身份、冻结当前配置，保留停止代次与旧结果隔离。
- **历史图片行为保持**：审计第 1 项「旧消息里的图片也随上下文发送」经用户复核符合「全部带图发送」的既定产品决定，保持现状，不恢复「仅发送文字」或图片能力门。
- **侧栏「工作区」入口收口**：工作区标题固定在导航与可滚动列表之间，项目/房间再多也不随列表滚走；打开/切换项目入口收进标题右侧（文件夹加号按钮），旧底部「打开/切换项目」条目移除；项目/房间空态与相关文案同步更新。用户手册「切换项目」说明随新入口更新。
- **审计回归进入默认套件**：新增 `tests/integration/backendAudit20261108.test.ts`（10 项，覆盖当前/未来文字图片、Q2 自身收到附件、历史图片继续传递、私信停止续接对照、按钮/消息两入口保留原成员与研讨子集、忽略未执行队列、成员停用/移出时原子拒绝与显式更换），`reminderBoundary` 增补「后来提交的请求不进入已创建提醒的输入」断言；独立审计入口保留在 `scripts/audits/`。
- **版本与交付**：此前 beta.40 只交付了 R195 界面改动，本版把审计修复与未提交的侧栏改动一起提交、构建并发布。
