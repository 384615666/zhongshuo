# 众说 0.1.3-beta.37

本版按 2026-11-07 的用户反馈完成四项界面改进：消息里的图片可以直接看到预览图、收藏页增加文字搜索、对话串与私信的消息头像放大到 50×50、设置页隐藏两项不用的数据入口。数据库格式保持 schema 61，升级保留项目、聊天、附件、任务与草稿。

## 主要改动

- **消息图片预览**：图片附件不再只显示文件名和黑色圆点图标，消息卡会显示真实图片缩略图；点击图片或「打开」可进入只读共享预览。普通文档仍保持文件图标，不额外读取图片。
- **收藏搜索**：搜索与收藏页的「收藏」页签增加文字搜索框，按收藏标题、链接或目标内容匹配；清空搜索即恢复全部收藏，项目范围与收藏数据不受影响。
- **消息头像放大**：对话串与私信中的消息头像从原尺寸放大到 50×50 像素；私信左栏列表头像与成员管理头像保持原样。
- **设置页精简**：隐藏「数据与存储」中的「最近一次数据操作」和「从旧版本导入草稿」两项；备份全部数据、使用已有数据恢复、草稿保存与清理、归档管理继续保留。
