# 众说 0.1.3-beta.35

本版按 2026-11-07 的七项反馈调整界面细节，并去掉正式版不应出现的开发口径提示。数据库格式保持 schema 61，升级保留项目、聊天、附件、任务与草稿。

## 文件与 Git

- 顶部工具栏与下方「项目文件 / Git」面板之间补上间隔（原来贴在一起）。
- 文件预览右上角「⋯」菜单去掉「引用到 选择讨论位置」；菜单保留：文件信息、下载原文件 / 另存为、限宽阅读、自动换行、关闭此文件、关闭所有文件。
- 非 Git 目录的 Git 页去掉「改动记录不受影响 / 任务改动仍会记录，并可查看 diff 与撤销」提示块；仍保留「尚未初始化 Git」空态与读取失败时的「重试读取」。

## 搜索与收藏

- 工具栏里的「搜索 / 收藏」两个页签与工具栏垂直居中（原来偏上）。
- 去掉「作者」筛选（不再按作者过滤）。
- 输入关键词时不再弹出「按 Enter 或点「检索」开始」提示；检索中状态由「检索」按钮显示。
- 去掉「范围：「X」· 搜索范围为消息、线程和任务标题，不含文件正文」「… 收藏总计 N 条」「在线程回复消息上点书签按钮即可收藏；收藏不会改动原内容…」等说明文字；当前范围由左栏选中的项目卡表达。

## 提示居中

- 成员管理、任务看板、搜索与收藏的空态（如「输入关键词开始搜索」「还没有收藏」「这个范围里还没有任务」）改为在内容区垂直居中，不再贴在顶部。
