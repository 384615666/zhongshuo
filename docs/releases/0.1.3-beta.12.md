# 众说 0.1.3-beta.12

- 默认成员头像按渠道显示：Claude 使用 Claude 娘，DeepSeek Harness 使用 DeepSeek 娘，Codex 使用白龙娘，Pi 使用 Pi 娘。修正旧版统一补入的默认图，并保护明确保存的自定义选择。
- 私信列表展示侧栏可见项目，按项目分组；项目与会话按最近回复排序，显示当天时间、昨天、前天或完整日期。每组有自己的添加按钮与归档会话折叠入口。
- 新建私信点击一位成员即可打开，减少确认步骤；请求绑定点击的项目，连点与回执丢失重试不重复创建。
- 超宽屏下成员卡片和任务卡片与各自分组标题左对齐。
- 普通任务、私信与研讨不再自动注入完整项目文件清单。输入只补充项目工作目录和按需查找说明，明确引用的附件和既有权限继续生效。

安装前正常退出众说；升级保留聊天、项目与任务记录，数据结构仍为 61。
Windows 数字版本为 `0.1.3.12`。
