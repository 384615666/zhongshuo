# 众说 0.1.3-beta.40

本版处理九项界面反馈：对话里的图片改成真实预览、房间引用改成结构化引用卡、所有对话面的操作按钮统一到气泡下方、非 Git 目录不再弹奇怪提示、私信在带鱼屏下状态条不再拉满整行、独立研讨成员列表统一、搜索「更多筛选」重排、去掉重复的「调整独立研讨成员」、并新增「我的名字」设置。功能合同、数据格式与 schema（61）不变，升级保留项目、聊天、附件、任务与草稿。

## 主要改动

- **对话内图片真预览**：房间里、对话串里、私信里的图片附件不再只是一个文件名，而是直接显示缩略图——单图按原始比例最长边约 220px，多图用 104×104 小网格；点击仍打开原来的只读预览，可以看大图。非图片附件保持文件卡/芯片；加载失败如实退回图标。
- **房间引用与对话串一致**：房间首页消息卡片下方的「引用」不再往输入框粘贴一段文字（旧实现还会截断），而是出现与对话串相同的「对话引用」卡片：原文完整保留、随消息发送，输入框只写新要求；选中部分文字再引用时只引所选。
- **操作按钮统一在气泡下方**：对话串与私信里「复制 / 引用 / 收藏」原先显示在作者行（气泡上方），房间卡片则在卡片底部；现在所有对话面的操作条都统一在消息内容（文字、图片、文件）下方，鼠标移上去或键盘聚焦时出现。
- **非 Git 目录不再报错**：文件夹不是 Git 仓库时，文件与 Git 页不再出现「Git 部分信息读取失败」「读取仓库状态未完成」，也不再显示 `fatal: not a git repository` 之类的英文原始报错；改为中性说明，不影响文件浏览与预览。真实 Git 失败仍会如实提示。
- **私信带鱼屏适配**：超宽屏幕上「待你处理」等执行状态条不再横跨整屏、文字和按钮分居两端；状态条内容限制在约 1024px 内并在对话列里居中，文字与操作按钮成组。普通宽度（1360 / 1873）布局保持不变。
- **独立研讨成员列表统一**：成员弹层每行改为单行等高：勾选、名字、右侧渠道与模型三列对齐；DeepSeek Harness 的长模型名不再把整行折成两行，只在右侧省略号截断（鼠标停留可看全文）。
- **搜索「更多筛选」重排**：展开后的日期与会话筛选改为整齐的第二行：日期两个输入框等宽、标签与控件同一基线、日期与会话分组清晰；收起后工具栏仍是一行 48px。
- **去掉重复入口**：房间与对话串的「本次运行设置」里不再有「调整独立研讨成员」——成员名单统一在输入区的「独立研讨 · N人」芯片里调整，「回到自然协作」仍用于关闭独立研讨。
- **我的名字**：设置 → 外观 新增「我的名字」。填写后，你自己发的消息署名、引用来源与私信署名都显示这个名字；留空保存则恢复显示「你」。改名只影响显示，不改历史消息正文，重启与升级后保留。
- **手册同步**：用户手册更新图片预览、引用、我的名字、独立研讨与搜索筛选说明；Git 说明补充「不是 Git 仓库时只会中性说明」。
