# 众说 0.1.3-beta.38

本版修正左侧栏的视觉问题：清掉一处从旧界面泄漏进新侧栏的样式，并把顶部导航、项目树、房间与底部设置统一到同一条左基线。功能、数据与格式不变（schema 61），升级保留项目、聊天、附件、任务与草稿。

## 主要改动

- **旧样式泄漏修复**：旧界面 `renderer/style.css` 里的 `.sidebar { padding:12px; gap:10px }` 会同时命中新侧栏。hifi 侧栏现在显式归零，整条侧栏不再内缩 12px。
  - 当前页面的蓝色选中竖条回到侧栏左缘，不再悬在侧栏中间；
  - 每一行的名称可用宽度增加 24px，长项目名/房间名不再提前出现省略号；
  - 顶部导航、项目区、底部设置三段之间多余的 10px 间距去掉。
- **统一左基线**：顶部导航图标、项目图标、房间状态位、底部「设置」图标全部落在 x=32；项目名与房间名同为 x=53，导航与设置名称 x=54。
- **设置入口对齐**：底部「恢复任务 / 设置」与顶部五个一级入口使用同一图标基线，不再向左突出 16px。
