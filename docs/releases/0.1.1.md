# 众说 0.1.1

0.1.1 是 0.1.0 的界面与品牌修复版本，不改变任务执行、数据格式与安装位置，可直接覆盖安装。

- **正式 logo 补到程序内**：欢迎页、favicon、窗口与数据操作窗口图标、数据操作页品牌位统一使用根目录 `logo.png`；安装器的卸载与操作手册快捷方式也使用正式图标（此前为系统默认图标）。
- **清理界面上的开发说明文字**：移除成员页工作量统计口径与「高级状态」诊断块、模板/房间名单长说明、AI 设置弹窗的副标题、思考等级来源、权限长说明和页脚提示，以及全前端同类的实现/验收口径、内部 ID、诊断 details、分页与时间戳说明；状态、错误、操作后果、真实数据事实和渠道安装步骤保留。
- **重做安装向导外观**：新的品牌侧栏图与页眉图标、简洁的中文欢迎/准备/完成页；去掉默认 Inno 许可页和纯文本安装说明页（许可证与安装说明仍随程序安装）；完成页可直接打开众说或操作手册。安装逻辑、目录、当前用户范围、数据保留策略均未改变。
- 操作手册 20 张界面截图随新 UI 更新。

安装 `Zhongshuo-Setup-0.1.1-x64.exe`，无需管理员权限。升级前请正常退出众说；可直接覆盖 0.1.0/beta 版本，聊天、项目、成员与设置保留。卸载保留用户数据。

安装包：`Zhongshuo-Setup-0.1.1-x64.exe`（159,306,032 字节），SHA256 `ba0c0747d902cee2e9fbb8688eb1aa1519337a95909a1f7d90e1321cd08c027d`。随 Release 另附 `.exe.sha256` 与 `.release.json`。

AI CLI 及模型渠道需要自行安装、登录和配置；众说不捆绑 API 密钥或模型额度。

此版本安装包未做 Authenticode 签名，Windows 可能显示未知发布者。随 Release 提供 SHA256 校验文件与构建元数据。
