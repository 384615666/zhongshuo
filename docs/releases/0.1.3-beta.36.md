# 众说 0.1.3-beta.36

本版按 2026-11-07 的用户反馈清理前端提示：提示里不再出现英文技术标识，括号及括号里的说明也全部去掉。数据库格式保持 schema 61，升级保留项目、聊天、附件、任务与草稿。

## 提示清理口径

- 只清提示类文案：报错、toast、错误条、空态、tooltip、placeholder、状态说明与确认文案。
- 去掉错误码、命令名、参数名、枚举值与技术英文：VALIDATION_INVALID 这类错误码不再上屏；HEAD、diff、stash、base/ours/theirs、origin、CLI、Shell、fake、runtime、owner、hooks、LAN、ISO/IANA/UTC、HH:mm、SHA-256、CA、UTF-8、KB/B、tokens、hash、ID 等改为中文或去掉。
- 提示里的所有中文/英文括号及括号内容去掉；必要状态改写成不带括号的短句，安全关键信息（结果未知、输入已保留、原件保留等）不丢失。
- 产品名与格式名保留：Git、AI、PDF、Word、Office、Markdown、HTML、DOCX、XLSX、CSV、JSON、PNG/JPEG/WebP、GitHub、DeepSeek、Claude、Codex、Pi、Harness 及模型名；文件路径、文件名、URL 原样保留。

## 主要改动

- 中央清洗 `userFacingSystemText` 升级：自动去掉错误码前缀、命令名、参数赋值、已知道具英文与括号；路径/文件名/网址先占位保护，避免误伤。
- 去掉直接拼进提示的错误码前缀：成员启停、成员资料、成员绑定、房间发送/重发等入口只显示中文原因。协调者停用失败现在显示「操作失败：协调者不可停用」。
- 渠道与权限文案中文化：运行渠道显示「Claude / Codex / DeepSeek Harness / Pi」，不再显示「Claude CLI」；权限档位显示「只读分析 / 项目内文件编辑」等中文名；思考等级、token 用量、文件大小提示改用中文单位。
- 任务详情、执行状态、恢复与阻塞说明：状态枚举、诊断事件、发件箱状态改中文；诊断折叠层同样不再出现错误码与英文。
- Git 页：HEAD/detached HEAD、diff、暂存、共同祖先/本方/对方、origin/远端、提交钩子等说明改为中文说法；导出格式菜单改为「导出 Markdown/HTML/DOCX 记录…」与「Markdown/Word 聊天记录」。
- 设置页：数据与草稿存储、远程访问、诊断信息等提示去英文和括号；工程键收进中文诊断说明。
- 旧界面与契约层：旧渲染器 230 余处提示同步清理；数据复制/位置/调用预算/通知/文档校验与主进程对话框的用户可见文案去错误码前缀与括号。
- 新增测试：`userFacingTextR119` 覆盖新清洗口径；`userCopyR119` 新增全 hifi 提示范围的括号、技术英文与错误码插值守卫；相关旧断言按新口径更新。
