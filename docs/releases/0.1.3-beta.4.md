# 众说 0.1.3-beta.4

本地候选版，补齐中断任务的检查与恢复入口。

- “核对执行结果”改为“检查中断”。从父任务打开时，直接检查真正阻塞它的成员及子任务。
- 显示已保存答复、文件和最后动作。没有完整结果时明确说明，不再要求用户核对空结果。
- 程序确认旧执行结束后，才提供“解除占用”；随后可回原任务继续。保留未知结果和原记录，不自动重发。
- 针对旧版本已丢失退出记录的任务，提供 Windows 重启后的程序核查路径；重新打开众说或睡眠不会被当作重启证明。

安装前从系统托盘右键退出众说，再运行 `Zhongshuo-Setup-0.1.3-beta.4-x64.exe`。聊天与项目文件保留，数据结构仍为 61。若检查面板提示旧版退出记录缺失，请保存其他工作并重启 Windows，再检查中断、解除占用后继续任务。
