# 众说 0.1.3-beta.2

本地候选版，修复四项使用反馈。

- 输入框右键新增全选、复制、剪切和粘贴菜单，按实际选区、只读和密码状态启用，沿用系统原生编辑行为。
- 补齐执行并发设置。上一版“允许成员并行”只控制文件写入互斥，项目和渠道仍默认最多运行 2 位。现在默认全局、每项目、同渠道均为 4，可在 **设置 → AI 设置 → 同时运行的 AI** 中分别调整为 1–32，保存后对排队执行生效；调低不会取消在途任务，依赖与保护继续有效。
- 移除私信菜单的“在原界面打开”和其他普通页面中的开发过渡入口，任务详情使用当前界面打开。
- 移除房间文件页未接保存动作的“文件选区评论”演示弹窗。真正的附件评论在预览 **⋯ → 评论此文件**，保存到附件来源会话，保留版本且不自动派发给 AI。

先从托盘正常退出旧版，再覆盖安装 `Zhongshuo-Setup-0.1.3-beta.2-x64.exe`。数据结构仍为 61，保留聊天、成员、设置及项目文件。本次未发布到 GitHub，安装包未签名。
