# 众说 1.0.3

本版修复「AI 设置」里选择渠道后，下拉选项不会自动关闭的问题。数据格式与 schema（61）不变。

## 更新

- **选中后自动收起**：「AI 设置」弹窗里的渠道下拉，选中某一项后选项列表立即关闭，按钮直接显示新渠道；不会再出现“已经选中 Codex，列表仍展开”的情况。
- **同类下拉一并修复**：同一个自绘下拉组件在各处共用，因此「思考等级」「权限模式」、成员管理顶部的状态筛选，以及添加 AI、模板编辑里的渠道/权限选择也一起修好。
- **原有操作不变**：键盘 ↑↓ + Enter 选择、点击外部关闭、关闭后再次打开、选中当前值不重复保存等行为保持原样；只修复选择后的收起时机。
- 版本号 `1.0.3`，Windows 文件版本 `1.0.3.65535`。

## 原因与范围

设置行通常写成 `<label class="field">` 包住下拉。点击选项（普通 `div`）时，浏览器的 label 激活行为会向内部 combobox 按钮补发一次点击，把刚刚关闭的列表重新打开。修复方式是在下拉容器的捕获阶段取消这次点击的默认动作，选择逻辑与外观不变；不改数据、权限、命令与 schema。
