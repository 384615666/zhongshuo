# 众说 0.1.3-beta.52

本版按用户 2026-11-08 反馈：设置页**状态小字也去掉**，并把「众说 · 本地多成员协作工作台」改为「众说 · 本地多Agent协作工作台」；由于前两版连续删除了页头/分区/行内说明和状态文字，本版同时**重新排版设置页**（行高紧凑、标签与控件垂直居中、去掉空档）。功能与数据格式不变，schema 仍为 61，升级保留项目、聊天、附件、任务与草稿。

## 改动

- **去掉状态小字**：
  - 「我的名字」下方「当前显示「你」/当前显示「xxx」」；
  - 开关右侧的「已开启/已关闭」「开启/关闭」「显示/隐藏」文字（保留开关本身与无障碍名称）；
  - AI 设置「同时运行的 AI」下方「当前上限：全局 … · 每项目 … · 同渠道 …」以及「读取中… / 尚未确认当前上限」；
  - 设置里嵌入的归档管理器：无归档时不再显示「共 0 个项目 · 0 个房间」和空的筛选/刷新行，只留「没有归档内容」（有归档时筛选与列表正常显示）。
- **版本名称**：「众说 · 本地多成员协作工作台」改为「众说 · 本地多Agent协作工作台」（只改显示文案）。
- **重新排版**：
  - 设置行统一为紧凑行高（约 46px）、标签与控件垂直居中；头像/归档/诊断等大控件行单独顶部对齐，不再留下小字消失后的空档；
  - 分区头内边距收小；分段之间只保留 18px 间距，不再叠加 margin（原来段间空 40px）；
  - 头像选择器去掉底部 margin；嵌入的并发面板摊平卡片外边距与行高；归档为空时折叠筛选行。
  - 状态/结果/错误（保存失败、危险提示、清理结果、诊断详情等）仍保留，它们是功能反馈，不是装饰小字。
- 未改设置行基元、其他页面、数据与命令。
