# 众说 0.1.3-beta.49

本版修复用户反馈的设置页「我的名字」行排版问题。功能与数据格式不变，schema 仍为 61，升级保留项目、聊天、附件、任务与草稿。

## 问题

设置 → 外观 → 「我的名字」这一行，输入框与「保存」按钮比其它行（主题、显示头像等）的控件更靠右，几乎贴到卡片右缘；下面的「当前显示「你」」也悬在卡片边缘，整行看起来像没对齐。

根因：`.settings-card-body > .pset-row` 给设置行统一加 `13px 20px` 内边距，但「我的名字」行被包在 `[data-zs-viewer-name]` 容器里，不是 `.settings-card-body` 的直接子级，因此这条规则没有命中；该行退回到 `.pset-row` 默认的 `padding: 10px 0`，横向内边距为 0，控件就顶到了卡片边缘。

## 修复

- `src/ui/hifi/styles/r170-settings.css`：为 `[data-zs-viewer-name] > .pset-row` 补上与其它行相同的 `13px 20px` 内边距；窄窗（≤760px）同规则收窄到 `14px`，与其它行一致。
- 未改设置行基元、控件顺序或数据逻辑；其它包裹型设置行（通知总开关、调用预算等）原本已有对应规则。
