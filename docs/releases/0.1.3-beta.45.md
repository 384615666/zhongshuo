# 众说 0.1.3-beta.45

本版把另一个 AI 在工作区完成的「对话串页签简化 + 串内成员管理」改动原样提交并打包。功能、数据格式与 schema（61）不变，升级保留项目、聊天、附件、任务与草稿。

## 主要改动

- **对话串页签简化**：对话串顶部从原来的「回复 / 成果 / 详情（内部分组：任务概况、活动与进展、运行详情、研讨记录…）」收敛为 **回复 / 成果（讨论串为附件）/ 参与成员**；任务状态与「继续任务 / 结束任务」仍固定在串顶状态条，交付验收仍从「成果」进入。旧链接 `?tab=task/activity/run/deliberation` 自动落到「参与成员」，`?tab=delivery` 仍打开成果确认，不出现旧详情分组。
- **串内成员管理**：新增「参与成员」页，直接列出本串成员，可 **移出** 或 **添加到本串**；成员页只显示名单与管理操作，不再顺带加载任务详情。写入使用 `thread.members.change` 的版本号（expectedVersion）核对，冲突时刷新后重试；被移出的成员不再收到该串后续消息。
- **用户手册同步**：第 4/6/12 节按新页签改写（不再引导「详情 → 活动与进展 / 运行详情」），新增「参与成员」截图 `26-thread-members.png`，进度截图 `08-progress.png` 更新为新的状态条；`docs/user-guide/index.html` 由手册重新生成。
- **回归辅助同步**：`tests/browser/helpers/r153ProductNavigation.cjs` 更新为新的线程导航断言（成员页、版本号增减、交付仍在成果下），`scripts/lib/user-guide-scenes.js` 第 8/26 场景改为新界面。
- 本版代码由另一个 AI 在工作区完成；主控按用户要求原样提交，未改其设计，只在干净 worktree 中复验后打包。
