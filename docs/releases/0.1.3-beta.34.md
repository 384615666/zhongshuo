# 众说 0.1.3-beta.34

本版统一「成员管理 / 任务看板 / 文件与 Git / 搜索与收藏」四个页面的左栏与顶部栏外观，消除页面之间的割裂感。数据库格式保持 schema 61，升级保留项目、聊天、附件、任务与草稿。

## 四个页面统一

- **项目卡片**：四页统一为「项目名 + 一行小字」——成员管理显示房间数与成员数，任务看板显示任务项数，文件与 Git、搜索与收藏显示「Git 仓库 / 非 Git 目录」；卡片高度、字号、颜色、选中态一致。
- **左栏标题**：四页的「项目」标题字号、颜色、位置一致。
- **顶部工具栏**：四页统一为同一条灰底圆角工具栏（同高 48px、同内边距、同控件高度 30px）。文件与 Git 页原来的白底顶栏（路径 + 文件/Git 页签 + 仓库状态 + Git 操作）与搜索页原来的「页签一行 + 筛选行一行」都收进这条工具栏。
- **搜索框**：成员管理与搜索与收藏共用同一个搜索框组件（放大镜 + 外框，30px 高），外观与行为一致；成员页仍保留输入即过滤，搜索页仍是回车检索。
- **搜索与收藏**：作者 / 日期 / 会话筛选收进「更多筛选」（默认收起，展开为同一工具栏内的第二排）；当前范围说明移到工具栏下方一行；没有当前项目时自动切到「全部项目」范围，不再停在「尚未打开项目」。
- **任务看板**：「全部项目」卡片小字改为「侧栏可见项目 · 共 N 项」。

## 验证

- 新增 R189 四页一致性验证：四页工具栏 computed 样式逐项相等、位置与宽度相同（1360×900 与 1873×740 两档实测）、工具栏与左栏标题顶部对齐、工具栏内控件均 30px、四页卡片字体与高度一致且小字非空；功能回归覆盖成员页搜索过滤、搜索页回车检索、看板工具栏按钮。
- 结果：R189 50/50 断言通过；R188 回归 14 场景 124 断言通过；R183 回归 15 场景 86 断言通过；相关浏览器测试 4 文件 18 项通过；hifi 类型检查 0 错。
