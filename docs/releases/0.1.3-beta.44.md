# 众说 0.1.3-beta.44

本版只改一处界面细节：左侧「文件与 Git」的图标。功能、数据格式与 schema（61）不变，升级保留项目、聊天、附件、任务与草稿。

## 问题

用户 2026-11-08 截图反馈「文件和 git 的图标是不是有问题」。侧栏「文件与 Git」此前复用了 `diff` 图标——那是分支/差异示意图（两条线 + 两个小圆圈 + 折线），在 14px 侧栏尺寸下圆环被压成小点、整体像一段残缺的笔画，不像一个完整图标；且它表达的是「差异」而不是「文件」，与「文件与 Git」这个入口语义也不符。

## 修复

- 侧栏「文件与 Git」改用 `file-text` 图标（文件页「文件」页签同一图形），14px 下清晰可辨，与其余侧栏图标的线性风格一致；`diff` 图标仍在差异/Git 相关位置使用（Git 页、文件改动卡等），语义不变。
- 未改布局、尺寸、颜色、hover/选中态与点击行为。
