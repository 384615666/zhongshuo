# 众说 0.1.3-beta.5

本地候选版，让中断任务可以直接继续。

- 遇到“执行中断”时，在原任务点 **继续任务**，程序处理旧执行留下的占用并继续工作。
- 无需重启 Windows、填写原因，也无需先手动“检查中断”或“解除占用”。旧版本退出记录缺失时同样按此操作。
- 保留已有回复、文件和中断历史，未知结果仍如实记录。任务详情可供查看，继续任务无需先完成诊断步骤。
- 只有明确点击继续或发送新要求后，才会继续处理任务。

安装前必须从系统托盘右键选择 **退出众说**，等待后台任务结束后，再运行 `Zhongshuo-Setup-0.1.3-beta.5-x64.exe`。右上角 **×** 只隐藏窗口；程序或后台仍在运行时，安装器会拒绝安装，不会自动关闭众说。聊天与项目文件保留，数据结构仍为 61。

本版替代 beta.4 中“重启 Windows → 检查中断 → 解除占用 → 继续”的操作步骤。Windows 数字版本为 `0.1.3.5`。安装产物及最终验证结果以源码冻结后的验收记录为准。
