# 众说 0.1.3-beta.10

测试版，把应用设置整理成一页，并补齐通知开关与项目链接。

- **设置改成一页**：通用、外观、通知、AI 设置、数据与存储、帮助与关于从上往下排在同一页，不再有左侧分区菜单；右侧搜索框仍可直接定位到具体那一项。
- **通知新增总开关**：在「通知」一段可以整体关闭桌面通知。关闭后不再弹出系统通知，任务与未读照常保留；关闭期间产生的提醒不会在重新开启后补发。
- **操作手册改为外部打开**：在「帮助与关于」点「打开手册」，用系统默认浏览器打开随程序附带的离线手册，与当前版本一致。
- **帮助与关于新增项目链接**：GitHub 仓库（https://github.com/384615666/zhongshuo ）与产品主页（https://zhongshuo.lsjx.xyz ）。
- **去掉不再需要的入口**：「通用」里的「打开一个定位链接」与整段「连接与设备」已隐藏；「AI 设置」不再显示本机运行状态详情。需要定位任务时，仍可在任务、看板、活动等处直接跳转。
- 清理界面里开发过程的说明文字（例如通知空态的引导句、诊断区的内部键名）。

本版保留此前已合入源码的预设头像、成员模板头像、宽屏布局、托盘 AI 工作量面板与一键继续恢复。

安装前请从系统托盘右键选择 **退出众说**，等待程序退出后运行 `Zhongshuo-Setup-0.1.3-beta.10-x64.exe`。右上角 **×** 只隐藏窗口；安装器不会自动关闭运行中的众说。升级保留聊天与项目文件，数据结构仍为 61。

Windows 数字版本为 `0.1.3.10`。
