# 从正在使用的 v23 升级到 v24

工程不会操作你正在使用的 v23 目录。v24 提供独立程序包；旧程序、旧数据和完整备份保留。

1. 在众说中正常关闭窗口，等待关闭完成。如果提示任务仍在收拢，等它完成；不要同时运行两个副本。未知发送保持未知，不点击重发来“准备升级”。
2. 把整个 `desktop-daily-win-v23-rc6` 文件夹复制成一个明确标注“v23 完整备份、不要日常启动”的新文件夹。必须包含 `server-data` 全部内容（包括数据库及伴随文件、原件、逻辑根身份和 `electron-user-data` 浏览器资料），不能只复制 `state.sqlite`。
3. 准备一份**从未启动**的 `desktop-daily-win-v24`。它应有 `ZhongshuoDual` 和 `start-desktop.bat`，还没有 `server-data`。把上一步备份内的整个 `server-data` 复制到这个 v24 文件夹中。不要将两个已使用的数据根合并；若这份 v24 已经使用过，保留它，另取一份全新程序目录再做本步。
4. 只启动这个 v24 的 `start-desktop.bat`。原项目仍指向原磁盘目录；复制数据根不等于搬项目。核对项目、成员及未发送草稿；原未知发送仍应有待确认提示。升级、重开和重连不会代你重发。
5. 如需退回，先正常关闭 v24，再启动第 2 步保留的**完整 v23 备份及其匹配的旧程序**。不要给旧程序塞入 v24 使用后的部分数据库或浏览器资料；v24 期间新增的数据仍保留在 v24 目录。不要同时开启两个继承同一数据身份的副本。

本轮没有新增迁移，001–051 保持不变。工程将用自有 v23 完整工程根实际验证这条路线：含已提交但回执丢失的原信封、提及、图片引用、仅记录意图、草稿与原件，正常 BAT 升级和匹配完整回退；工程成绩不代替对你私人数据的验收。最终验证结果及 BUILD 见本轮交付记录。
