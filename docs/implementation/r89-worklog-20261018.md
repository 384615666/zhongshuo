  再走 `attachment.upload*`，正文显示 `@文档：文件名`，实际 attachmentRefs 进入既有提取
  通道。候选只来自当前项目与当前会话，文档不计为收件人。

  参与者建立子任务；无 @ 保留原协调者 AUTO/串内协作 handoff。
