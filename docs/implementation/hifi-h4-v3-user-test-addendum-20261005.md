## G1–G2：导航、看板与输入

- G1：Ctrl+K 输入“默认房间”，必要时用上下键选中**房间**结果再 Enter；再打开面板，用 Esc 关闭。标题栏应显示“演练·模拟派发”。关闭键暂时不点。
- G2：看板点任务卡，应定位到任务线程；切“当前项目/全部”。如果只有一个项目，两种范围内容相同是正常的。房间输入“整理任务要点@”，选 Guide A，应保留成员芯片并消费触发的 @。看未指定成员的 M0 提示前，**先移除 Guide A 芯片**；这是发送前提示，不必额外发送一条无指派任务来制造受阻。

## G3–G4：先返工，再检查切换，最后验收

1. 私信页点“+ Guide A”创建会话 A；发一条有正文的任务，例如“请总结当前目录【短测A】”。等回复及待验收面板；超过指南预期仍没有就截图反馈，不反复重发。
2. 在 A 点“要求返工”，填写一句意见并提交。应能看到意见已记录。**提交意见不会自动执行**；点一次“执行返工”，等待自然出现的新交付 v2。等待期间不重复点击。
3. **此时暂停 G3，先做 G4**：在 A 的 v2 上点“验收通过”打开确认框，但不要确认；再打开头部“重命名”并输入一个名称，但不要保存。
4. 点左侧另一个会话 B。两个编辑框应消失，B 的名称和原有任务状态应保持。回 A，应仍能正常打开 v2 验收框。
5. 现在在 A 点“验收通过→确认验收”。应提示验收完成。此时再回填 G3/G4。如要测试正常改名，重新打开重命名框后保存。

原清单按 G3 全部验收后再做 G4，会找不到“验收通过”；这属于步骤顺序问题。G3 已完成时，可用另一条新的待验收任务做 G4，无需重复返工整条链。

## G5–G8：导出、查找、预览与设置

- G5：任一有消息的会话导出 MD，应打开导出目录；归档后只读不能发送，取消归档后恢复。
- G6：搜索“回归”，日期**起、至先留空**并确认有命中；“至”设昨天；随后**清空“至”**，再把“起”设今天。不要同时保留“起=今天、至=昨天”。用今天确实存在的消息判断日期效果。切会话范围时选目标下拉项；如有同名房间，记录选项名称。收藏一条可操作的消息→收藏页可见→取消收藏；活动流定位任务应跳到对应线程。
- G7：线程“成果与附件”选一份附件，核类型/版本，打开预览、切宽度/展开、Esc退出展开、引用、关闭。**若引用时处在“成果与附件”标签，关闭预览后切“回复”再查看输入框中的引用**。再开关两次，面板不应叠加。无需重复六格式矩阵。
- G8：设置中的“显示仓库状态”按实际按钮切显示/隐藏，文字应及时更新，最后恢复原值；若按钮点击即保存，不用寻找额外保存键。成员 runtime 显示应如实；恢复检查只观察正常状态或记录注意项。
