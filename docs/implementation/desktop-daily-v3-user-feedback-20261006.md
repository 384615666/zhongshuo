## 2. 已回答的产品决定：只有文件、没有正文

本次异步澄清问题：“只发送文件、没有正文时，你希望怎样处理？”

用户选择：**“沿用当前模式：默认发给 AI，选‘仅记录’时只保存（推荐）”。**

落实要求：

- 没有正文但有可发送的就绪文件引用时，允许发送，不强迫用户填写占位正文。
- 意图沿用当前显式模式：默认 AI；“仅记录”保存消息与文件，不派发、不扣模型预算。不因正文为空而静默改成记录。
- 真正空白且没有就绪文件仍拒绝；上传中/失败资源不当作就绪附件。
- 房间路由、DM 可见范围、图片能力门、版本/hash/范围、未知回执与同号同参重试等合同保持。仅有未认证图片且用户选择“继续文字”时没有可用文字，不得形成空模型输入，要给出添加文字/仅记录等可行选择。
- 不合成假用户正文，不把界面说明当模型文件内容；文件名可用于合法标题/消息卡呈现。

## 3. 既有决定继续有效

电脑端日常使用和完整原型还原优先；复用已有认证运行时/配置。工程零新增真实模型调用。Android、安装器/签名/自动更新、价值评价、DEV-11、并行写入等既有延期不借本次反馈重开。旧包、回填、CA、用户配置/历史/草稿/未确认账本不能用清库方式处理。

本次不要求用户再次跑完整测试清单或主动制造故障。工程先按独立夹具和实际事件证据修复，候选完成后只安排必要自然使用确认。
