## 2. 选型证据支持与需要纠正的报告口径

本次查看真 PowerPoint 样本的表格/图表对照、Word 对照、稀疏表格差异图。A 的真实表格与参考布局接近，图表内容可见，轻量路线值得作为默认候选。用户的选型决定不是“全部格式、安全与复杂文档已经认证”的声明。

1. “常规用户文件不受影响”不能由一个 PowerPoint 2007 保存的 8 页样本推导。报告应写本批样本表现与未覆盖项。
2. 原型的手造 dense/rich 文件 PowerPoint 无法打开，参考采用 LO。稀疏表格是否属于有效格式兼容缺口，还需用可被 Office 打开的独立生成器样本确认。AI 生成文件（例如 PptxGenJS、python-pptx）不是可忽略的用户类型。边框差异与数据/结构丢失分别判读。
3. 冷转换时间在样本上确有显著差异；内存 134MB 与202MB不是数量级差距，且两者采样对象不同。报告不应称“性能与内存均差一个数量级”。
4. 当前 metrics.json 已与报告部分具体数值不同：office 首开 43+2+69=114ms，最长翻页41ms。可正常解释为后续复跑，但需报告绑定 runId/文件 SHA256，不把未绑定或被覆盖的数字作为唯一证据。
5. A 的 reopen 明确重新解析，仅模块加载复用，不等于附件解析缓存命中。B 的 hot 是字体元数据等热路径，也不等于跳过转换。
6. 报告把 B 的展开182MB称“安装器 +182MB”口径不对；压缩下载71.4MB、展开、正式封包增量分列。B本次不分发，此项不阻塞A接入。
7. SUM结果与缓存值都为7不能证明“不重算”。将来评估B的Excel兜底须用公式预期值与保存缓存故意不同的反例；本次Excel保持现链，不引B重算。

## 3. 外部资源与取消证据尚不充分，集成时补测

### 外部资源

报告把外链目标图片先移除后，A占位、B空白，判为“不加载外部资源”。但失效目标可以是“不尝试读取”，也可以是“尝试后失败”，两者不能混判。现有脚本没有相关请求计数器。

要求：用可达的受控本地HTTP服务与存在的临时文件作外链目标；登记请求/读取尝试，验证没有自动外联。链接点击走宿主URL策略与用户动作，不允许预览自行导航或调用高权限bridge。前端库默认值不能替代产品策略。

### A取消

当前 `route-a/metrics.json` 的 `cancel.hugeAbort100ms`：

```json
{"fetchMs":142,"openMs":83,"ok":false,"errorName":"Error","errorMessage":"PPTX zip limit exceeded: ppt/media/junk.bin is 125829120 bytes > maxEntryUncompressedBytes 33554432"}
```

这是超限拒绝，不是AbortSignal生效证据。脚本先把全部文件 fetch/arrayBuffer 后才创建取消器，100ms计时也不覆盖字节读取。

要求：使用合法且在产品限额内的较大文件，确定在加载/解析/渲染阶段发生取消；关闭、换附件、切会话、迟到事件均不能恢复旧面板，监听器/字体/Blob URL/图表实例与缓存按所属生命周期释放。增加长任务期间UI可操作性与有界截止验证，不能因小样本快就写“同步解析无长任务”。

边界读取也须提前执行产品自己的字节限额，避免先把126MB放进renderer造成379MB峰值才依靠ZIP护栏拒绝。

## 4. 第四十轮接入要求

### PPT

- 固定版本与完整来源指纹，vendor构建可重复，依赖/许可证材料随实际产物归档；全部资源本地，不走CDN。
- 保留RECOMMENDED_ZIP_LIMITS并按产品限制收紧；附件大小、解压量、对象/页数、图片和嵌入字体各有界。库能渲染pptm不改变产品已有宏容器拒绝合同。
- 新预览从正式、获准、核验hash/实根/版本的原件读取入口获得字节，不开通任意本机路径读取。
- viewer解析/DOM/事件的生命周期绑定attachment+hash/revision+conversation/project+预览代次；迟到结果不得覆写或重开旧面板。
- PDF原有4.10链不盲升。PPT的EMF/内嵌PDF回退如启用v5，独立本地资产和明确配置；未提供时明确关闭，不能隐式远程加载。SmartArt/EMF等未实测项分别留档。
- 当前图表几何限制可如实说明，但类别/系列/数值/文本完整性必须验证。没有可靠检测时给清楚的兼容预览范围说明，不能宣称所有普通文件均无影响。

### Word

- docx-preview75KB不是完整增量；现有原型还加载JSZip。A浏览器单文件内部的JSZip不当然可由Word共享，正式构建按实际依赖度量。
- 增加多页、表格、图片、页眉页脚、分页与中文混排正例及外链/坏文件/超限反例。样式限定在预览容器，避免污染聊天UI。
- 视觉与正文提取分列。保留Mammoth及模型输入水位/版本/权限合同，失败不冒充读到完整文档。
