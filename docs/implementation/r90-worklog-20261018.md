## 复核补充：附件内容身份

- 检查会话指出并已复现：旧去重键使用文件名、大小、mtime、MIME，同名同大小但内容不同
  会被误跳过；失败后重选也存在被错误压制的风险。
- 现改为读取实际字节 SHA-256 作为内容身份。只有名称、大小和内容 hash 都相同才去重；
  上传项持久化 `contentHash`，ready 回执的服务器 hash 同步回填；failed 项永不参与去重。
- 产品源提交 `ea231762f86dc9b53759779585f9ec26dc763956`。

  attachmentId 与 SHA-256 均不同；无效 UTF-8 上传失败后，同名同大小有效文件重选成功。
