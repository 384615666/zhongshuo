## 首次误报记录（保留为检测器缺陷证据，非产品失败）
- `首次误报-daemon级-summary.json`：9/11，失败项 `decoy-off`（"decoy 结束后仍检出 1 个"）与
  `residual-zero`（"包路径残留 1 个（pid=40252）"）。
- 根因：Git Bash（MSYS）把 `./众说-便携-win-x64/...node.exe` 解析为完整 Windows 绝对路径写进
  验证脚本**自身主进程**命令行；残留检测的 PS 查询只排除查询辅助进程（`-ne $PID`）与被跟踪
  子进程，从不排除验证器主进程——`.cmd` 相对路径启动时靠"命令行不含包绝对路径"碰巧不匹配，
  MSYS 下即误报（decoy-off 检出的"1 个"即验证器自身）。
- 处置：第十八轮已修源内三处（独立包两模板+开发机 verify-desktop.mjs）为**显式排除自身 PID
  与辅助进程身份**（`ZS_PROC_EXCLUDE`），并新增三壳（.cmd / PowerShell 绝对路径 / Git Bash）
  本地回归测试。修复只进源——**冻结包 bld_c2f364d06ff0014e 不改动**；下次打包自然产生新
  buildId。用户无需为此再跑整包。
