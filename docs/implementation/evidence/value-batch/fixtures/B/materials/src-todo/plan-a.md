# 方案 A：停机窗口内一次迁完（同步迁移）

## 思路
选一个周六凌晨 2:00–2:30 的维护窗，停写 → 全量 dump 传输 → 新库导入 → 切流量。

## 步骤
1. 周六 01:50 冻结写入（应用只读模式）。
2. 02:00 开始 mysqldump 全量导出（预计 15 分钟，库约 40GB）。
3. 传输到新机器并导入（预计 8 分钟）。
4. 02:25 应用切换连接串到新库，恢复写入。
5. 02:30 对外恢复服务。

## 预计停机
全程 30 分钟以内。

## 回滚
若导入失败，改回旧库连接串即可（旧机器仍在机房，只是已下线服务）。

## 优点
- 流程简单，一次性完成，不需要写双写逻辑。
- 时间点可控，容易和业务方沟通。

## 缺点
- 停机窗口内任何一步超时都会直接影响恢复时间。
