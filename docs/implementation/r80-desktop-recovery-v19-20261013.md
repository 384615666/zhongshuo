## 根因与修复

旧管道监测首次重连失败后不再安排下一次检查；独立命令后来连接成功也不通知renderer，界面可永久离线。原监测代码的受控反例保留。现在共享单个认证过程及监测器，明确恢复中/失败/挂起/在线，失败退避、握手有截止、退出取消；成功从实际认证路径统一通知。重连只恢复读取，没有重派发业务写命令或自动继续队列。挂起返回只读核实服务；计时预算用monotonic时间，墙钟只作显示。

真实界面发现同线程delivery→run深链URL已更新但页签仍旧，原因是内部changeTab没有同步urlTabRef；修一行同步本次意图，不清导航状态。阅读位置恢复增加有界、独立命名空间元数据，历史选择和稳定页游标仍在正式只读接口按作用域重核。相同时钟容量反例改成单调序号；活动预览标签在12项上限内优先保留。跨详情分组的清理阶段读新DOM、写旧scope，曾把open=true变false；已改为保存最后实际阅读快照。各原失败均保留，不用后续成功代记首次成功。

原另存和部分上传直接写目标，写入中断会截断已存在原件。现在wx独占同目录临时文件、完整写入和fsync之后rename作为提交点；失败只处理本次创建的临时件，旧目标不变。服务端登记事务和文件提交边界如实区分：SQLite只读可拒绝登记，而blob可能已经写入；不把部分完成说成整笔成功，也不自动删唯一原件。

帮助/关于加入实际可用的查看与复制本地诊断。复制只取结构化允许字段；错误只复制码/时间/方法，不复制错误全文、草稿或消息。数据根用路径身份hash，配置来源/失配用脱敏类别。BUILD、模型ID、服务、草稿存储和未知数量均来自真实读取；未提供就显示未提供。原生指针复制与剪贴板内容核对，不拿程序化.click失去用户手势的失败充当按钮通过。
