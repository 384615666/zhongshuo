## 1. 本轮补测项（R6/R7 + 相邻视图切换 + 监听显示）

### R6 PPT 视觉页预览（**桌面端**——远程面无 PPT 预览入口）
1. 打开房间「**默认房间**」→ 主池样本消息卡片 → 点「**打开回复串（…条回复）→**」→
   回复串顶部**根消息**（正文「R40 短回归·PPT 预览样本…」）下点击「📎 回归幻灯.pptx」芯片
   → 预览面板出现两栏：**提取文本卡片**（模型输入真源）+**视觉页预览**（pptx-renderer 本地渲染）。
2. 视觉页区：「上一页/下一页」翻页内容变化；缩放下拉（适应/100%/150%/200%）尺寸变化；页码「第 n/N 页」。
3. **图表页应实际显示柱状图**；表格页显示网格。
4. 预览面板右上工具条：**「⤢ 展开预览」**——视觉区放大（可再收起）；面板下缘可拖拽调高。
5. **关闭**：点「✕ 关闭」或消息内「关闭预览」→ 预览**必须真正消失且不占空间**（v5 现场
   「点了没反应」已修——关闭前后各拍一张）。
6. 切别的会话再回 → 重新打开正常（无残留/半开状态）。
**通过判据**：翻页/缩放/展开真实生效；图表/表格实际渲染；**关闭真正消失**；重开正常。

### R7 Word 视觉预览与样式隔离（桌面，约 1 分钟）
1. 打开任一会话 → 点发送框「**📎附件**」→ 选包内 `samples/word-r7-sample.docx` → 发送框
   芯片区出现「📎 word-r7-sample.docx」→ **点击芯片**（产品无拖放入口；只预览即可，不要求发送）。
2. 预览面板：「视觉预览（docx-preview…Shadow DOM 隔离）」——3 节分页/表格/图片/页眉
   「众说预览选型核对…」正常呈现，下方提取文本卡片（与视觉分列）。
3. **「⤢ 展开预览」**后视觉区放大到可舒适阅读（v5 现场「区域过小」已修）。
4. **样式隔离核对**：预览打开前后，聊天界面按钮/文字颜色不变。
5. 关闭预览 → 真正消失。
**通过判据**：视觉呈现+可展开阅读+界面样式不变+关闭真正消失。

### V1 相邻视图切换（桌面，约 1 分钟）
1. 房间主池 → 点侧栏私信 → **主池与其输入区必须真正收起**（不再被挤成细条）：
   私信消息区应占据主要阅读高度。
2. 私信 → 返回主池（← 返回主池 / 侧栏房间）→ 主池与输入区恢复。
3. 主池 → 打开任一回复串 → 线程视图正常（主池收起、输入区仍可用）。
**通过判据**：三向切换各自收起/恢复；私信消息区高度过半（截图一张）。

### V2 监听显示（桌面，约 1 分钟）
1. 「远程访问（DEV-25）」面板启用（局域网）→ 展开面板：**监听选择框应显示已应用的
   「局域网（0.0.0.0）」**（v5 现场「实际 LAN、下拉却显示仅本机」已修），说明行有
   「已应用配置：监听 …」。
2. 把下拉改为「仅本机」→ 面板刷新（收起再展开）→ 选择保持你的编辑（不被刷新覆盖），
   说明行标注「检测到未应用的编辑」；点「启用」后编辑成为已应用配置。
**通过判据**：运行事实与已应用配置一致呈现；编辑不被刷新覆盖。

## 3. 边界与如实声明

- v6 使用**新数据根**：首次启动生成**新 CA 与新服务证书**——两枚指纹与 v2/v3/v4/v5 不同，
  客户端须重新导入 v6 的 `server-data/remote/ca.cer` 并核对新「信任根指纹」。
  **「IP 变了只重签服务证书、CA 不变」只适用于同一数据根**，不跨包继承。
- v5 包及其 RESULTS/截图原地保留（正式回填记录）；v6 独立目录、独立数据根。
- 短回归通过 ≠ D 系全项重测；Android 实测另按指南执行（适配≠实测）。
- 本包仍为模拟运行（fake+真实派发硬防护），零真实模型调用。
