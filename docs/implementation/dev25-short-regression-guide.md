# DEV-25 v4 修复包·受影响项短回归指南（2026-10-03 第三十九轮）

> 适用包：`dist/desktop/dev25-dual-win-v4`（修复候选包）。**不需要 SQL、Node、开发者工具**——
> 全部步骤只用双击启动器+浏览器+截图。前置状态由包的种子自动准备（见 §0）。
> 本指南不重复 D1—D10 全套；只覆盖第三十八/三十九轮修复的受影响项。

## 0. 前置状态（种子自动准备——启动后即有）

双击 `start-server.bat` 后，应用应自动打开「DEV25 短回归」项目并已就绪：

| 前置项 | 就绪形态 | 你看到什么 |
|---|---|---|
| 会话「恢复演练」（私信 Guide A） | 含一个**中断待恢复**的任务 | 会话头显示「中断待恢复 1（…上次运行 interrupted）」+「恢复执行」按钮 |
| 会话「队列演练」（私信 Guide B） | 队列处于**暂停**态 | 会话头显示「队列已暂停（停止后）」 |
| 房间「默认房间」 | 两名启用 agent 成员 | 发送框旁出现「不指派（自动路由）」下拉（含 @ Guide A / @ Guide B） |
| 附件区 | 已预置一份 PPT 附件 | 房间发送框芯片区有「回归幻灯.pptx」芯片可点击预览 |

若以上任一未就绪：停止，记录截图（这是要报的缺陷，不要继续测）。

## 1. 六项回归（每项 1—3 分钟）

### R1 中断任务的「恢复执行」
1. 打开会话「恢复演练」→ 确认头部有「中断待恢复」与**恢复执行**按钮。
2. 点「恢复执行」→ 头部应显示「恢复执行已入队（任务…）」，任务开始执行（执行态呈现）。
3. 等待完成（模拟运行数秒—60 秒内）→ 「中断待恢复」标注消失。
**通过判据**：按钮可点、有明确反馈、执行推进、标注消失。
**失败示例（要截图）**：点了没反应/无任何文字反馈/中断标注永远不消失。

### R2 「继续队列」与反馈
1. 打开会话「队列演练」→ 头部「队列已暂停（停止后）」+「继续队列」按钮。
2. 点「继续队列」→ 头部应显示「已继续队列（泵出 N 条…）」或「已继续：当前无待处理的排队消息」。
**通过判据**：两种反馈出现其一（明确文字——不再静默）。
**远程端同样测一次**：浏览器任务区的「执行态=paused」行有「继续队列」按钮，点击后事件流出现「已继续…」。

### R3 侧栏与项目恢复（桌面）
1. 完全关闭应用窗口 → 重新双击 `start-server.bat`。
2. 应用应自动恢复项目（侧栏房间列表+私信列表出现，无需手动 Reload）。
3. 私信列表中的会话应显示标题或最近消息预览（区分同成员多会话——不再是一排相同名字）。
**通过判据**：重启后侧栏自动回来；会话行可区分。
（可选加测：重启后立刻操作不卡死——启动恢复自带有界重试。）

### R4 防护模式绑定拦截
1. 桌面 → 项目设置 → 成员行「绑定…」→ 选 claude → 模型填 `deepseek-flash` → 保存。
2. 应出现**明确错误**：「验收防护模式（ZS_REAL_DISPATCH_GUARD=1）下不可绑定真实 runtime（claude）…请保持 fake…」。
3. 改选 **fake（模拟——验收防护包唯一可绑定渠道）** → 保存 → 成员行显示 fake。
**通过判据**：真实渠道被正式拒绝（有文字）；fake 可绑并回显。

### R5 设备列表可达（远程）
1. 桌面「远程访问」面板启用（局域网）→ 配对一台客户端设备。
2. 面板向下滚动：**已配对设备列表**应可达（能滚动看到+「吊销」按钮可点），64 位指纹芯片在窄栏内换行显示、不遮挡。
3. LAN 地址列表：每行地址可点击复制；若有 198.18.x.x 之类地址，应有「虚拟网卡/隧道常见段…」标注。
**通过判据**：默认 100% 缩放下设备区可滚动可操作；虚拟网卡地址有标注。

### R6 PPT 静态页预览（本地+远程桌面均可）
1. 点击附件芯片「回归幻灯.pptx」→ 预览面板出现两栏：**提取文本卡片**+**静态页预览**。
2. 静态页区：「上一页/下一页」翻页内容确实变化；「放大/缩小」页面尺寸变化；页码标签显示「第 n/N 页」。
3. 图表页：显示「图表（静态页不渲染）」占位标注+页签标注「含未渲染对象」——**不是空白页**。
4. 关闭预览 → 重新打开 → 头部「缓存=命中」。
**通过判据**：翻页/缩放真实生效；图表页有明确降级标注；重开命中缓存。

## 3. 边界与如实声明

- v4 使用**新数据根**：首次启动生成**新 CA 与新服务证书**——两枚指纹与 v2/v3 不同，
  客户端须重新导入 v4 的 `server-data/remote/ca.cer` 并核对新「信任根指纹」。
  **「IP 变了只重签服务证书、CA 不变」只适用于同一数据根**，不跨包继承。
- 短回归通过 ≠ D 系全项重测通过；Android 实测另按指南执行（适配≠实测）。
- 本包仍为模拟运行（fake+真实派发硬防护），零真实模型调用。
