## 三、评分方法

- **机核维度**（自动）：要点命中率、漏项数、预设错误/异常召回、误报数、实际调用数
  （usage_records）、耗时（事件时间线）、失败成本（中断/修复次数）。
- **人工维度**（用户）：可行动性——材料匿名编号（A1/A2、B1/B2、C1/C2）并**隐藏模式
  标签**，用户在不知道哪份来自哪种模式的情况下评定（评定者盲；双方实施者均不参与
  评判，不称"双盲"——材料制作为施工方，非盲）。
- 不以 unanimous 与否、篇幅、行动条目数量单独判定质量更高；分歧处理维度仅记录事实
  （互评是否产生真实修正），不预设研讨更优。
