- `member.update` 绑定 project/member/settings_revision，只更新名称、说明；保留成员 ID、runtime profile、会话、任务和历史正文。名称去两端空格后 1–60 字，说明最多 200 字。归档/移除拒绝，CAS 冲突不覆盖。

- 新增迁移 049：`member_templates`，不复用可变 `agent_profiles`。001–048 不改。模板创建复制 whitelist 配置到 `ap_<newMemberId>`，不继承认证、会话、任务、成果、未知发送记录或项目路径；无自动派发。
- 执行程序仅做文件/PATH 查找，不启动 CLI、不宣称模型认证。缺失程序可保存，但成员卡/详情明确说明不可派工。派发及图片认证原复查保留。

- 成员操作独立有界本地账本（64 项/256 KiB），发送前耐久保存 commandId/原参数；未知不自动重试，关闭/重开后人工同号重放。添加、配置与启停也接入。读取/保存失败与未知分列。
