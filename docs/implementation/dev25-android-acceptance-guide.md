# DEV-25 Android 实机验收指南（第四十五轮修订——使用当前 v6 包）

> **口径**：Windows 四项短回归（R6/R7/V1/V2）已按 v6 范围收案（2026-10-04，正式记录
> `dist/desktop/dev25-dual-win-v6/RESULTS/SHORT-REGRESSION.md`）；本指南为 Android 实测准备，
> **在现有 v6 包与其数据/CA 上执行，不换包、不清库、不重新导根**。「证书格式已适配」＝两层
> 证书（本地 CA+CA 签发服务证书）在设计上兼容 Android 用户凭据信任路径；「该 Android 组合
> 已实测」＝以实际执行回填为准，未执行不记通过。私钥/CA 私钥只留服务机；**不使用任何证书
> 错误绕过开关**（不点「继续前往」冒充信任）。手机/Android/浏览器**实际版本必填**（模板见文末）
> ——不同厂商设置入口名称可能不同，按语义找。

## 0. 前置（Windows 服务机——v6 正在运行）

1. **先恢复 LAN 监听**（Windows 短回归 V2 结束时应用过「仅本机」）：远程面板把监听改回
   **局域网（0.0.0.0）**→「启用」→ **LAN 自检通过**，确认实际地址可达（当前为
   `https://192.168.1.100:端口`——**端口以当前面板显示为准**，不要沿用旧包/旧截图端口）。
   从 **LAN 地址列表**选手机可达地址；**不要用 198.18.x.x/169.254.x.x 虚拟网卡地址**
   （面板已标注「不是其它设备可达的地址」）。
2. v6 对应 CA（`dist/desktop/dev25-dual-win-v6/server-data/remote/ca.cer`）文件
   **SHA-256=`c7655e12c4102fad83bf1b0f9d26fb667c81e9a568d1df624475321eef42b9b0`**——传到手机
   前/后都按此指纹核对（CA 证书是**公开**文件，不含私钥；微信/邮件/USB/网盘传输均可）。
   服务机核对命令（包目录下 PowerShell）：
   `Get-FileHash -Algorithm SHA256 server-data\remote\ca.cer`。
   不要复用 v2—v5 时期导入的旧 CA（各包数据根不同、CA 不同）。

## 1. 证书信任（Android 用户凭据）

1. 手机「设置 → 安全 → 更多安全设置 → 加密与凭据 → 安装证书 → **CA 证书**」
   （不同厂商路径名称略有差异：也可能是「从存储设备安装/安装数字证书」；MIUI 在
   「设置→密码与安全→系统安全→加密与凭据」；Pixel 在「设置→安全→更多安全设置→加密
   与凭据」）。
2. 选择传入的 `ca.cer`——系统可能显示「检查证书/无视风险」提示（因为它是自建 CA），
   确认安装到**用户凭据**。安装列表应出现 CA 主题（CN=Zhongshuo Remote Access CA）。
   如系统提供证书详情/指纹视图，与第 0 步 SHA-256 指纹逐位核对。
3. 打开手机浏览器访问面板地址：应**无证书警告**（锁形/「连接是安全的」）。仍告警=信任未
   生效（部分浏览器需完全重启后生效；Samsung Internet 与 Chrome 均读系统用户凭据）。
   **不点「继续前往」**——先解决信任。

## 2. 配对与基本操作（触摸）

1. 服务机**现在**点「生成配对码」（5 分钟一次有效——信任已完成再生成）。
2. 手机浏览器打开配对页 → 输入 pairingId + 8 位码 + 设备名（如「我的手机」）→「配对并保存」
   → 进入主界面（IndexedDB 保存设备凭据）。
3. 触摸操作检查：会话下拉选择、线程行点击读取、发送/仅记录按钮、附件按钮（调起系统文件
   选择器）、任务区停止/验收按钮。
4. 「仅记录」一条消息 → 事件流出现 `message.submitted`（D2 对应）。

## 3. 上传（D3 对应）

- 点「附件」→ Android 文件选择器（照片/文件）→ 选小文件 → 芯片出现 → 发送 → 消息带 📎。
- 注意：**图片输入能力未认证**（IMAGE_INPUT_UNVERIFIED 门）——图片附件发送默认会被明确
  拒绝并提示；用文本类文件（.txt/.md）做上传+发送演练，或图片走「仅记录」。

## 4. 后台恢复（D7 对应——确定步骤，不依赖种子任务窗口）

1. 手机浏览器选好一个会话（与桌面正在看的同一会话）→ 把浏览器**切后台/锁屏 30—60 秒**。
2. 手机在后台期间，**由 Windows 桌面端在同一会话发一条带唯一标记的「仅记录」消息**
   （例如正文「后台恢复标记-20261004-01」——标记自拟、当次唯一即可）。
   不要依赖种子首任务 60 秒停滞窗——多次操作后该窗口早已消耗。
3. 手机回前台：
   - 页面应自动重连（事件流出现 connected/续传线）；
   - **刚才桌面代发的标记消息可见**、会话状态恢复一致（检查点续传——无漏）。
4. 若页面被系统杀掉：重新打开地址 → 凭据复用免配对 → 历史与任务状态恢复（同样核对标记消息）。

## 5. 独立吊销（D8 对应——**放最后执行**）

1. 服务机远程面板「已配对设备」中对**手机设备**点「吊销」。
2. 手机应立即：事件流断开并出现**终态横幅**（设备已被吊销——不再自动重连）；任何操作
   返回 401。
3. 吊销时若还有其它已连接设备（如 Windows 客户端浏览器）可顺带观察**不受影响**（设备级
   授权代次）；未观察到的部分如实另记，不补写通过。
4. 重新配对（可选复核）：服务机重新生成配对码 → 手机「清除本机凭据」→ 重新配对。
