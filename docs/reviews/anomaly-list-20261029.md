# 当前异常清单

2026-10-29，基于 V65 的 R124/R125 测试。以下沿用对用户说明时的编号，并补入 19、20；这是异常表现与行为边界清单，不代表 20 个独立漏洞。产品修复尚未开始，原数据未操作。

| 编号 | 异常或边界 | 实测结果与范围 |
| --- | --- | --- |
| 1 | AI 运行程序退出，任务仍挂着 | 正式任务链中，一条成功后共享进程退出，另一条仍运行并占名额；默认无执行截止。R124 P03。 |
| 2 | 房间归档后，排队任务仍执行 | 归档成功，之前尚未启动的根任务随后实际写文件。R124 A05。 |
| 3 | 笔记保存故障拖住全局 | 一条笔记合并的表级写入故障使其他项目八个任务零启动；持续故障也阻止重启调度器。R124 存储两路径。 |
| 4 | 矛盾的运行编号被同时接受 | 开始通知和响应编号矛盾，错误正文进入正式聊天回复。异常运行端协议，R124 P02。 |
| 5 | 旧会话输出混入恢复后的新会话 | 旧会话关闭后迟到的开始/正文/完成被新会话认领。底层公共接口已复现，未宣称本例在正式聊天落库。R124 P10。 |
| 6 | 异常状态被当作完成 | 完成通知的状态为取消、仍在运行、空值、缺失或未知时，正式任务仍成功。五个变体是同一问题，R124 DeepSeek S1。 |
| 7 | 审批身份矛盾仍可同意 | 审批同时指向不同会话，底层仍发出同意；未执行真实工具。异常协议，R124 P05。 |
| 8 | 重复审批编号覆盖原请求 | 后一个会话覆盖待答绑定，原请求答复失败，后一个可发同意；未证明两个真实命令执行。R124 P06。 |
| 9 | 旧审批答复发给新进程 | 回答已退出进程的旧审批会启动新程序，握手前先发旧同意。底层已复现，未证明真实服务端接受授权。R124 P09。 |
| 10 | 启动失败后的同会话重试被卡住 | 明确启动错误后旧等待记录未清，后续正常重试未到运行端。底层公共接口，R124 P07。 |
| 11 | 旧进程启动记录挡住新进程 | 旧进程退出后的未绑定记录阻止新代次启动；关闭旧会话后恢复。与 10 相关，R124 P08。 |
| 12 | 迟到成功未保存共同笔记 | 正式恢复泵把未知轮次收为成功并交付，但笔记丢失，重放和重开不补回。R124 C08。 |
| 13 | 重复停止重复增加计数 | 同一仍在停止的运行，五个请求使停止计数从 0 到 5；未发生已证重跑或错误放锁。R124 A03。 |
| 14 | 请求编号冲突误报存储故障 | 发送与停止共用请求编号，误报存储不可用；实际未发生存储故障或改目标。R124 A01。 |
| 15 | 完成后适配器继续传消息和终态 | 底层仍输出终态后正文及重复/矛盾终态，正式任务处理层挡住了覆盖。R124 P04，底层加强项。 |
| 16 | 停用 AI 后正在连接的任务仍可启动 | 现行规则将已有派发记录视为在途，停用不影响这次执行。属于规则边界，不计为已证违约。R124 A06。 |
| 17 | 直接改库可让笔记来源版本错认 | 必须直接篡改隔离数据库中的输入记录；未发现用户或模型经业务接口改写的入口。存储完整性加强项，R124 C09。 |
| 18 | 被独占文件的修改前内容不可恢复 | 真实 Windows 独占锁下前后内容均记录为未知，其他工作继续；关闭占用后新请求可读。属于能力边界。R124 存储文件锁场景。 |
| 19 | 同一会话未结束时底层可再次启动 | 首轮响应已回而无终态，底层允许另一 transport session 续接同一 provider thread 并启动；正式私信队列仍依次执行，其他串可并行。底层边界，R125 S1。 |
| 20 | 已完成运行编号复用使新私信挂起 | 正式私信第二轮续接同一 provider thread，运行端重用旧编号时，响应前新消息进入旧流、响应后归属冲突，合法终态也被丢弃；新任务仍运行且无回复，旧可见回复不变。仅换成新编号的对照正常完成。R125 S2。 |

第 20 项另有底层同一 SessionRef 的分支：新响应覆盖映射后，迟到旧正文会被标为新轮；现有正式 worker 不复用同一 SessionRef，因此不能把该分支直接说成正式新回复已被污染。正式链已证的是新任务挂起。

尚未证实的猜想继续不计入异常：强制删除重建并复用角色身份是否串记忆、成功提交后改变停止/保护状态是否造成业务恢复卡死。未发现强制复用身份或任意重放记忆合并的公开入口；安全门禁重验和历史笔记不撤销也不能单独当作缺陷。

R124 的 39 项与 R125 的 5 项使用脚本业务模型、本地协议进程和独立数据库；预期失败固定反例，不能把测试框架绿色写成产品全部通过。未测试真实提供方一定产生畸形协议，也未运行用户原任务。
