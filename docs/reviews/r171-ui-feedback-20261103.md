## 实现要点

- `MembersPage`：选中项目作用域；`command('room.list',{projectId})` 本地房间列表；写操作/扫描
  回读条件改为页内项目；`data-zs-members*` 选择器保留，新增 `members-project-rooms`。
- `useFormGuard(projectId, {scopeProjectId})`：可选页内作用域，**不传时与原来完全一致**；
  `MemberManagementForms` 的编辑资料/保存模板/从模板创建/添加 AI/AI 设置透传。
- `App.tsx`：侧栏项目名按钮只切换展开状态（tooltip/aria-expanded 同步），不再切换项目。
- `MessageChangedFiles`：文件按钮顺序与复合按钮圆角类；`ExecutionStatus`：线程横幅单行化。
- 截图夹具扩展为 4 个隔离演示项目（读书会筹备 + 社区运营/产品手册/数据分析），用于验证
  独立项目卡、切项目不联动侧栏与房间数不闪 0；`scripts/capture-r170-ui.cjs` 增加 members-switch 场景。

## 风险 / 说明

1. 侧栏项目名改为“只展开/收起”后，切换项目需点该项目下房间、项目 ⋯「项目主页/成员管理/项目设置」
   或顶栏项目菜单；这与用户反馈一致，但依赖旧语义的验证脚本（如历史 `verify-dm-project-r158.cjs`）
   需要同步更新才能复用。
2. 成员页与侧栏解耦后，页内选中项目与侧栏当前项目可能不同；页面目前只用左卡高亮表达，未加额外提示。
3. 线程横幅在很窄的线程栏里按钮仍可能换行（一行内容已省略）；宽窗下为单行。
4. 成员数/房间数的防闪 0 只保证“未就绪不显示数字”，不改变命令返回时序。
