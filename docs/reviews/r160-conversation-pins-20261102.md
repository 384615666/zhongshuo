# R160：房间与私信独立置顶

## 行为

按用户提供的 Codex 侧栏截图，为房间和私信分别提供独立的「置顶」区：房间在项目列表上方，私信在项目分组上方。置顶后原分组不重复列出，取消后回到原项目；置顶项显示所属项目，同名内容可以区分。项目折叠或隐藏不遮住置顶，点击按明确 ID 跨项目进入对应房间或会话。新置顶排在前面。

列表项悬浮显示更多菜单，右键也可操作；当前私信标题的更多菜单提供相同入口。置顶保留头像、回复时间、未读与执行状态。隐藏项目只把置顶的私信纳入入口未读汇总，不混入该项目的其他私信。

## 实现边界

- 置顶是个人显示偏好，按本机 viewer/client 分开，存入现有 daemon_state，数据结构仍为 61，不迁移聊天或任务。普通 navigation.set 不触碰置顶，避免普通导航覆盖它。
- navigation.pin 在命令事务内增删单个引用，沿用 commandId 幂等；校验目标项目、类型、私信参与者和归档/移除状态，重放同样核对当前对象可用性。取消置顶允许清理失效引用，不删除会话或房间。
- navigation.get 从真实目标投影名称，过滤归档与移除项；客户端并行操作按各自目标合并，禁止同目标连点；迟到的启动快照不能覆盖已发生的置顶修改。回执未知时保留原界面状态并提示重试，重复设置同一布尔值不会创建副本。
- 私信继续使用各项目独立索引；置顶引用可读取所属隐藏项目，普通分组仍只显示侧栏可见项目。没有读到列表时使用服务端真实名称作为入口，读取失败可重试。
- 手册补充置顶说明与第25张截图，截图使用独立合成数据，未发送真实模型请求。
