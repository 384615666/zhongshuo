## 逐条诊断与修复

### 1. 「打开新的工作区」按钮选中/hover 底色位置不对
- **复现/度量**：`getBoundingClientRect` 显示按钮 24×20、`padding: 6px 12px`、图标 x 偏移 12px 且溢出右缘 2px。根因是 `.side-heading button` 只设了 `width:20px;height:20px`，没清掉通用 `button` 的 padding——`box-sizing:border-box` 下 20px 宽度小于左右 padding 总和，按钮实际 24px 宽，图标被 padding 推到右侧，hover 底色（按钮盒）与图标错位。
- **修复**：`base.css` 的 `.side-heading button` 增加 `padding: 0; flex: none;`。度量：按钮 20×20、padding 0、图标中心 219 = 盒子中心 219，hover 底色 `rgba(31,60,90,0.09)` 正常出现。

### 2. 工作区按钮 tooltip
- `title` / `aria-label` 改为「打开新的工作区」（忙碌时「正在打开新的工作区」），不再写选择文件夹/前台切换说明。

### 3. 去掉顶部「众说」旁的切换工作区组件
- `TitleBar.tsx` 删除「当前项目 ▾」按钮、`ProjectMenu`、菜单边界/状态/ref，以及 `titlebar.css` 的 `.zs-tb-project*` 规则与 focus/响应式引用；标题栏只剩品名「众说」、异常连接状态与窗口三键。项目/工作区切换由侧栏「工作区」按钮与项目列表承担（打开新工作区不受影响）。
- 更新 `tests/integration/r90TitlebarButtonContract.test.ts` 为「无项目下拉」新合同。

### 4. 去掉搜索里的「退出键」「回车键」提示与按钮
- `CommandPalette.tsx` 删除右上角 `<span class="kbd">退出键</span>`、选中行 `<Tag>回车键</Tag>`，以及 placeholder 里的键盘说明；键盘行为（↑↓/Enter/Esc）保留。`Tag` 导入随之移除。

### 5. 「最近活动 X 秒前」不换行
- `LiveProgress.tsx` 活动行把长活动文本包进 `.live-progress-activity-text`（可省略），时间标签用 `.live-progress-ago`；`components.css` 设活动行 `flex-wrap:nowrap`、文本 `white-space:nowrap; overflow:hidden; text-overflow:ellipsis`、时间 `flex:none; white-space:nowrap`。度量：时间标签高 18.7px、活动行高 18.7px（单行），长命令省略。

### 6. `file:///` 本地文件只显示文件名 + 右键操作
- 新增纯函数 `src/ui/hifi/lib/localFileHref.ts`：仅接受 `file:` 绝对路径，支持 Windows 盘符、百分号编码、UNC；http(s)/mailto/相对路径返回 null。
- `MarkdownView.renderInline` 识别 `![...](...)/[...](...)`，本地路径渲染为 `LocalFileLink`：文件图标 + 文件名（不再出现 `!`、`↗` 或 `file:///` 原文），左键默认程序打开；右键菜单 **复制文件地址 / 用默认程序打开 / 在文件管理器中显示 / 用 xxx 打开**（打开方式来自 `zsLocalFiles.openers`；复制走剪贴板窄桥）。CSS 在 `preview.css`。
- 非 file 链接保持原「文本 + 外链标记」行为；不加载图片、不注入 HTML。
