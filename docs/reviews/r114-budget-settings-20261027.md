# R114：关闭预算时隐藏提示，补齐已有设置的搜索

用户要求关闭调用预算时隐藏输入区提示，并检查已有设置是否遗漏入口。本轮沿用精简原则，前端由 deepseek-flash/max 子代理处理，设置读写与遗漏检查由 gpt-6.1-sol/medium 子代理处理，主代理审查改动并独立验证。

## 修改

- 预算关闭时，房间、回复串和私信输入框不再显示“调用预算未启用”，“本次运行设置”也不显示关闭态预算段。
- 预算开启后保留次数上限、独立研讨编辑和既有发送载荷；读取失败的错误仍可查看。
- 开关原本位于“设置 → AI 设置”。补充“调用预算”“调用次数”“次数预算”等搜索词，搜索结果直接定位预算行；导航描述和预算说明使用简短中文，上限数字只显示一处。
- 为既有头像编辑、归档管理、已移除项目补齐设置搜索和定位目标。
- 手册第11章加入开关使用步骤及编号截图，通用图文教程更新为14章18图。

`repoStatus.visible` 只控制旧界面的仓库状态条，正式界面已使用文件与Git页面，本轮没有添加这个旧界面的开关。导航展开、阅读位置等持久化记录属于界面状态，不新增用户设置。没有新增后端功能或工程环境变量控件。
