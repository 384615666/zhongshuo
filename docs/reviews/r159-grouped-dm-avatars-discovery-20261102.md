# R159：默认头像、项目分组私信、宽屏对齐与按需文件发现

## 范围与行为

用户指定 Claude / DeepSeek / Codex / Pi 分别用预设第 2 / 1 / 3 / 9 张；私信展示侧栏可见项目，按项目分组，各组有添加入口与最近回复时间；选择成员直接创建；成员与任务看板卡片在超宽屏左对齐。用户随后选择将每轮完整目录清单注入改为按需发现。

- 默认头像按稳定默认成员渠道 ID 映射。缺图或旧版无选择标记的统一 DeepSeek 图按渠道补齐；其他已存图片保留。新手动选择（含恢复默认）落单独标记，自动补齐用原图比较与同事务检查，避免覆盖显式选择或并发修改。新建成员随渠道切换默认图，用户选图后不再自动换；模板明确选择保留。私信列表中的非当前项目对端也补齐默认图。
- `conversation.list` 返回数据库消息的 lastMessageAt / lastReplyAt；回复时间只取最终 AI 消息，不用读取时间冒充。没有回复回退最近消息时间；没有消息不显示虚构时间。
- 独立项目索引缓存列表、加载/错误状态，迟到响应只更新原项目；主会话上下文仍按当前项目与装载代次维护。可见项目来自侧栏显隐/置顶集合，隐藏项目不读。组内会话与项目分组按最近回复排序，日期按本地日历显示 HH:mm / 昨天 / 前天 / YYYY-MM-DD，并定时跨日刷新。
- 各项目组有折叠、添加与归档会话入口。新建弹窗独立读取目标项目成员，点击一位成员即创建；同步在途锁防连点，回执未知沿同一 commandId 重试；已经创建但列表读取失败不再次创建。关闭弹窗后的迟到回执不抢导航。
- 两个数据页用具名页面类覆盖宽屏网格的自动左右边距，保留列宽上限，首张卡与标题/筛选行左边缘一致。
- 核对用户提供的问候会话，旧输入含 3139 条项目相对文件路径，并非这些文件的全文。旧设计在模型判断请求前无条件生成清单，用于帮助发现可读资料；当前 CLI 已能按需列目录、搜索和读取，没有必要对问候也发送全项目目录。
- 普通任务与私信信封增加项目工作目录，研讨各阶段使用同一说明，三个入口不再调用递归清单生成器。明确附件、获准材料及运行时权限不变；旧输入/历史兼容字段不重写，不重放原问候。
- 操作手册更新项目分组与一步创建说明，重拍 07-dm。
