# R172：R170 复核修复与 beta.22

用户授权修复 `761b002` 的独立复核问题，并打包发版。源码在公开仓库续工；不安装、不重启用户现有应用，不迁移或修改用户聊天/任务数据。沿用 R170 的十一项界面调整，schema 61 不变，零真实模型调用。

## 修复

1. 原行级 diff 对任意完整文本分配二维 JavaScript LCS 数组，6000 行隔离复现在 128MB 堆限制下 OOM。现在先剥离相同前后文，精确比较的中间区域限制为一百万格，用最多 1MB 方向数组和两个线性分数行；超出时明确按整段删除/新增显示，超过单侧一百万字符或五万行时分别显示有界文本。未改动上下文折叠，初始最多 500 行，每次增加 500 行，保留尾部改动。弹窗中的单侧缺失也复用有界展示。
2. 已存在的空字符串是有效空文件，仅 null/undefined 表示缺失。新增、删除与清空文件都参与红删绿增，缺失版本保留已知文本与原因。补齐旧两列容器中的通栏宽度。
3. 编辑器启动等待 `spawn` 事件才回成功，捕获异步 `error`，避免 ENOENT 在返回成功后变成主进程未处理异常。卸载或移动程序、失效选择均返回可读反馈。
4. 消息文件卡增加默认程序打开，按当前文件扩展名查询 Windows 推荐关联应用，Word/Excel 等随本机安装结果显示；源代码编辑器只补在文本/源码类型里。主进程通过 COM Shell 枚举与调用，不拼接或执行渲染器命令。IPC 只接受可信窗口、存在的绝对文件路径、当前扩展名重新枚举得到的哈希 ID。程序列表不再全局缓存，切文件时重查并丢弃迟到结果。中文、空格及斜杠路径兼容。

关联实现使用 [SHAssocEnumHandlers](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-shassocenumhandlers) 的推荐标记；绑定文件的 IDataObject 后由 IAssocHandler.Invoke 交给所选程序。复用已有 koffi，打包主进程从随包 daemon 原生依赖加载，无新增下载或安装依赖。

截图脚本改用正式 app.quit 退出链，避免 close 仅隐藏到托盘而残留隔离后台；不完整截图或子进程失败不再被汇总成成功。
