## 风险 / 说明

1. 看板「归档」是**看板视图层**的收起（localStorage），不是任务归档/删除；不可从界面“恢复全部”，
   只有最近一次操作的撤销（刷新/重开即无撤销入口），与用户本次要求一致。
2. 成员页首次访问的项目仍会显示加载态（没有缓存可用）；已访问过的项目切回不闪。缓存只在内存，
   重开应用后首次进入各项目仍加载一次。
3. 项目下拉替换为共享 Select 后，在极窄窗口下可能只显示截断的项目名（保留了 title 提示）。
