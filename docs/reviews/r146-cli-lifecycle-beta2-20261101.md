# R146 CLI 安装生命周期与 beta.2 测试包（2026-11-01）

用户要求将 R145 更新打包试用，重点检查首次没有 CLI、软件打开后新安装 CLI、卸载 CLI 三类场景，并覆盖重装与历史保留。

## 修复

- 扫描时读取 Windows 当前用户/系统 PATH，合并到本 daemon 的查找环境；保留原查找优先级，不写注册表或改系统环境。读取失败时保留旧 PATH，给出退出重开再扫描的说明。没有自动安装或卸载真实 CLI。
- 房间表要求非空协调者引用。零 CLI/空名单建房现在使用禁用占位身份满足约束，不创建启用渠道；解决原先新建空房间的 NOT NULL 事务错误。
- 在新房间首次发现成员后，再扫描原空房间时，替换占位者同时补入对应房间名单，避免协调者没有入房。自定义或有历史引用的占位身份继续保留；禁用、未绑定的同名手工成员不冒充可用协调者。
- 建房回执后同时刷新房间和项目成员，新增 AI 无需重启界面即可显示。
- 卸载后保留成员、模型、权限、启停选择和记录。成员名单返回独立的实时 `runtimeAvailable`，房间据此显示无可用 AI；新请求冻结执行配置前检查程序，缺失时事务拒绝且保留草稿。修复 Codex 程序已删除仍接受新任务，以及其他渠道直接暴露文件系统错误的问题。已接受的原请求同号重放保持原回执，不因之后卸载而改写。
- 重装后重新扫描复用原成员/profile，不新建重复成员，不自动重发旧消息或运行旧任务。
