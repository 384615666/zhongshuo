## 修复

- Git项目以已跟踪文件和未被忽略的未跟踪文件建立基线。已跟踪但后来被忽略的文件仍保留；忽略的构建产物、运行数据和依赖目录不进入源码基线。
- 非Git目录使用迭代扫描，移除默认5000文件截断；显式工程扫描限额仍如实报告。Git读取失败不降级为另一种范围的扫描。
- 基线持久保存范围类型、根目录身份及Git范围指纹。结束时保持同一范围，并合并全部before路径，避免文件仅因进入忽略规则或移出索引就被误认删除。
- 忽略规则、索引路径成员集合或Git大小写匹配配置变化时，新出现的路径不能直接推断为基线时不存在，记录unknown，避免撤销删除用户已有文件。
- 范围指纹包含祖先规则、Git专用与全局排除规则。工作树忽略文件不跟随符号链接；真实项目文件的链接越界、读取失败和根目录替换仍保持可核验错误。
- 基线失败显示具体路径和原因；全员启动失败后的运行说明沿用实际启动原因，不再只显示内部屏障规则编号。
