# R167 房间顶部合并（2026-11-02）

> 用户反馈「房间页顶部两条横条叠着，丑」，先按最小改动把房间头与页签合并成一行；此前尝试过的「整窗栏=各栏头」方案已被用户否决并回滚（见下方 §5）。

## 1. 做了什么

房间页原来两条常驻横条：

1. 房间头（约 40px）：房间名 + 成员 + 未读 + 预览重开 + ⋯
2. 页签行（约 40px）：对话池 / 任务看板 / 文件

合并成一条 **42px**：

```
对话池  任务看板  文件  ……………………  3 条未读   Claude · 2 名成员
```

- **房间名去掉**：侧栏里当前房间已经高亮（带未读圆点），窗口栏仍显示项目名，不再重复。
- **房间 ⋯ 去掉**：房间设置、成员、归档都在「点成员入口」打开的房间设置里，能力没有减少。
- **成员入口移到最右**，右端顺序为「未读数 → 成员」。
- **窄窗自适应**：≤1080 收紧内边距与成员 chip；≤960 隐藏未读标签、页签内边距压到 8px。

改动面：`src/ui/hifi/pages/Room.tsx`（+65/−80）+ `src/ui/hifi/styles/components.css`（+46）。窗口栏、侧栏、设置页、对话串列、私信均未改动。
