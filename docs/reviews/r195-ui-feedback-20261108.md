## 4. 非 Git 目录提示与英文 stderr

- 根因：daemon 的 `NOT_A_GIT_REPO` 结构码经 bridge 落到 `error.code`，消息已被 `userFacingSystemText` 清洗成中文；`refreshGitState` 只认 `msg.startsWith('NOT_A_GIT_REPO')`，于是普通非 Git 目录被当成真实读取失败，同时写 `readErrors.status` 与 `git.status` 的 `lastOp`，两块失败面板齐现并残留原始 git stderr。
- 修复：按 `error.code === 'NOT_A_GIT_REPO'` 或消息含「不是 git 仓库」/`not a git repository` 判定为中性（`isGit=false`、`notARepo=true`、清 `readErrors` 与 `git.status` 的 `lastOp`、不弹错；其它写操作的 `lastOp` 属各自事实，保留）。
- `userFacingText` 同步：非仓库消息统一收敛成「此目录不是 Git 仓库」；其它消息去掉 `fatal:`/`error:` 前缀，权限/路径/账号等安全关键信息原样保留。
- 文件与 Git 页两块失败面板加中性态门禁，只在真实 Git 失败时出现；Git 页失败原因也过清洗。非 Git 目录保持中性说明，不再占提示块。
