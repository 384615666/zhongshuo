# R190 七项界面反馈（文件与 Git / 搜索与收藏 / Git 空态 / 提示居中）

日期：2026-11-07。版本：0.1.3-beta.35。本轮只改前端展示（`src/ui/hifi`），不改 daemon 命令合同、不改 schema、不迁移用户数据、零真实模型。用户反馈基于已安装的 `0.1.3-beta.34`。

## 用户反馈（2026-11-07，附 7 张截图）

1. 文件和 Git 的顶部栏与下方「项目文件 / Git」栏需要增加间隔，现在贴在一起。
2. 搜索与收藏的两个页签按钮偏上；作者名不需要筛选了。
3. 搜索输入时不要出现「按 Enter 或点「检索」开始」提示块（图3）。
4. 去掉「范围：「默认项目」· 搜索范围为消息、线程和任务标题，不含文件正文」「… 收藏总计 N 条」「在线程回复消息上点书签按钮即可收藏；收藏不会改动原内容…」等开发口径文案，正式上线不保留。
5. 文件预览 ⋯ 菜单里的「引用到 选择讨论位置」去掉。
6. 去掉 Git 页「改动记录不受影响 / 任务改动仍会记录，并可查看 diff 与撤销」提示（图5）。
7. 各种提示（空态）偏上，应该居中。

## 实现

1. **文件页间隔**：`r188-files.css` 里 `.fg-rail-content > .fg-body` 的 `margin: 0 18px` 覆盖掉了共享 `.project-content > * + *` 的 12px 上间距，改为 `margin: var(--sp-3) 18px 0`；实测工具栏底部到面板顶部 12px。
2. **页签偏上 + 去作者筛选**：基础 `.thread-tabs` 带 `padding: 0 12px 6px`，进工具栏后把页签整体顶高 3px——工具栏内清零内边距（实测页签中心与工具栏中心同为 82px，±0）；作者名筛选连同 `author` 状态、`search.query` 的 `authorDisplayName` 参数与 `searchKey` 依赖一起删除（不再按作者过滤）。
3. **输入时不再弹提示**：删除「按 Enter 或点「检索」开始 / 正在检索…」整块；检索中状态由「检索」按钮自身表达。输入后初始空态也不再显示。
4. **去开发口径文案**：删除工具栏下方的范围说明整行（含 `data-zs-library-scope-note`）、收藏空态的「在线程回复消息上点书签按钮…」长说明、搜索空态的「按 Enter 检索，点击结果可回到原处。」说明；当前范围由左栏选中项目卡表达。
5. **预览菜单去引用入口**：`PreviewPane` 的 `quoteTarget` 改为可选 prop，未传时「引用到 …」菜单项与「引用选区」浮标都不渲染；文件与 Git 页不再传该 prop（线程/房间页行为不变）。实测文件预览 ⋯ 菜单只剩：文件信息 / 下载原文件 / 限宽阅读 / 自动换行 / 关闭此文件 / 关闭所有文件。
6. **Git 空态去提示块**：删除「改动记录不受影响 / 任务改动仍会记录，并可查看 diff 与撤销 / 返回文件」整块；保留空态标题「尚未初始化 Git」与读取失败时的「重试读取」。
7. **提示居中**：三页（成员/看板/搜索）的 `.page` 改为 flex 列、`.project-split` 撑满可用高度（左栏仍 `align-self:flex-start` + sticky），空态 `flex:1` 在整块内容区垂直居中——实测搜索空态中心与内容区中心差 30px（约半个工具栏高度），视觉上落在窗口中部；文件页空态同样居中。
