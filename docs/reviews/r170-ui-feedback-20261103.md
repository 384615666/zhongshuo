## 实现要点

- **本机打开方式发现**（`src/ui/localOpeners.ts`，注入式探测可单测）：Windows 下探测
  `%LOCALAPPDATA%\Programs\Microsoft VS Code\Code.exe`、`Program Files\JetBrains\*`
  与 JetBrains Toolbox 版本目录；非 Windows 返回空列表；路径校验要求绝对路径且真实存在文件。
- **主进程 IPC**（`src/ui/main.ts` + `src/ui/preload.ts`）：`zs:local-files.openers/reveal/openDefault/openWith`。
  renderer 只提交枚举 id 与已存在的绝对文件路径；可执行文件与参数由主进程固定清单解析，
  不回传可执行文件路径。所有 handler 走既有 `assertTrustedSender`（仅本应用窗口）。
- **渲染器路径解析**（`src/ui/hifi/lib/localOpen.ts`）：项目根 + 项目内相对路径 → 绝对路径；
  剪贴板优先 `navigator.clipboard`，失败退回隐藏 textarea；无本机桥时只保留复制能力。
- **消息卡数据链**：`MessageView → GeneratedFiles → MessageChangedFiles` 新增 `projectId`
  传递，保证只有附件路径（无 change 行）时也能还原绝对路径。
- **样式**：按工作流拆分 `styles/r170-{preview,members,board,settings}.css`，由
  `scripts/build-ui.mjs` 在既有 6 份样式后合并；未改共享 `base/components/tokens`。
- 看板隐藏集合是**本机视图偏好**（localStorage），不是任务归档；换设备/清缓存后卡片重新出现。
