# R189 四页视觉统一（成员管理 / 任务看板 / 文件与 Git / 搜索与收藏）

日期：2026-11-07。版本：0.1.3-beta.34。本轮只改前端展示与交互（`src/ui/hifi`），不改 daemon 命令合同、不改数据库 schema、不迁移用户数据、零真实模型调用。用户反馈基于已安装的 `0.1.3-beta.33`。

## 用户反馈（2026-11-07，附 4 张左栏截图）

1. 4 个页面（成员管理 / 任务看板 / 文件与 Git / 搜索与收藏）的**项目卡片和标题样式都不一致**，有割裂感。
2. 4 个页面的**顶部栏和搜索栏风格样式也不一致**。

已与用户确认统一口径（两个问题各选「推荐」方案）：
- 项目卡：统一「项目名 + 固定一行小字」；「全部项目」卡同样两行；
- 顶部栏：统一为**同一条灰底圆角工具栏**（复用 `.page-filters`），文件页与搜索页的页签收进工具栏。

## 实现

- **共享组件 `SearchField`**（`components/ui.tsx`）：外框 + 放大镜 + 输入，30px 高，与工具栏控件同高；支持 `onEnter`（输入法组合期不触发）与 `inputProps`（保留既有 `data-zs-*` 标记）。成员管理页与搜索页改用同一个组件——原来成员页是裸 `input`、搜索页是自制带外框行，这是「搜索栏不一致」的直接原因。
- **共享样式 `styles/r189-consistency.css`**（新增，已接入 `build-ui`）：
  - 工具栏内的页签（`.page-filters > .thread-tabs`）统一 30px 对齐、页签按钮 26px；
  - `.page-filters` 统一 `min-height:48px`、`filter-note` 行高 30px（消除 48/49px 的 1px 抖动）；
  - `.search-field` 外观（与 `.input` 同边框/圆角，聚焦用共享 ring）；
  - `.toolbar-tail`（右对齐动作组）与 `.toolbar-more`（工具栏内第二排）；
  - 文件页工具栏：单行不换行、路径可伸缩省略、状态条在工具栏内按原「inline」样式（去掉基础 `.fg-statusbar` 的 6px 内边距/边框/下外边距）。
- **成员管理**：搜索框改用 `SearchField`（保留 `data-zs-member-search` 与实时过滤）；顶部仍单条 `.page-filters`，状态/刷新/添加 AI 与看板同一种左对齐。
- **任务看板**：「全部项目」卡小字改为 `侧栏可见项目 · 共 N 项`（未知只写「侧栏可见项目」）；工具栏「刷新」按钮改用 `.btn.sm`（原来非 sm 高 32px，把工具栏撑到 49px）。
- **文件与 Git**：白底 42px `.fg-topbar` 改为 `page-filters fg-toolbar`（页签 → 路径 → 状态+Git 操作），并补齐页面右内边距（原来 `padding:0 0 18px` 让内容右缘比其它页多 24/40px）与首行顶部间距（原来工具栏比其它页高 20px）；状态条压成单行（原来多 span 折行把工具栏撑到 62px）；旧 `.fg-topbar` 白底样式从 `r188-files.css` 删除。
- **搜索与收藏**：页签并入工具栏，关键词改 `SearchField`；作者/日期/会话收进「更多筛选」（默认收起，展开是同一工具栏盒子的第二排）——原来全平铺会换成两行、比其它页高一截；范围说明移到工具栏下方一行（说明文字不是控件，放进栏里会撑行）；项目卡小字显示「Git 仓库 / 非 Git 目录」（原来空行），「全部项目」卡小字「侧栏可见项目」；无当前项目时自动落到「全部项目」范围，不再显示「尚未打开项目」把页面卡住。
- 四页左栏标题「项目」与卡片结构继续使用共享 `.project-rail / .project-card`，本页不再写私有字体/间距覆盖。
