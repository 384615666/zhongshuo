# R188 用户八项界面反馈（beta.33 候选）

日期：2026-11-07。本轮只改前端展示与交互（`src/ui/hifi`），不改 daemon 命令合同、不改数据库 schema、不迁移用户数据、零真实模型调用。用户反馈基于已安装的 `0.1.3-beta.32` 候选版。

## 用户反馈（2026-11-07）

1. 项目/房间可拖动排序修改后，鼠标放到项目和房间上就变成抓取样式；应该用正常鼠标样式，长按拖动时才变成抓取。
2. 成员管理/看板共用的项目卡左右间距更大了（图1）——要求收紧且左右相等。
3. 任务看板卡片的归档按钮 × 改成 √。
4. 去掉看板归档按钮的长提示（“归档（只从看板归档，任务本身保留，仍可在原对话串打开）”），改成「归档」。
5. 去掉任务看板里的「房间」选择（图2）。
6. 文件和 Git 菜单点击切换项目时会导致整个界面左移；改成和任务看板一样的项目卡片，替换原来的切项目组件。
7. 搜索与收藏也改成和任务看板一样的项目卡片，替换原来的切项目组件。
8. 文件和 Git 界面去掉图4「此文件夹未初始化 Git」提示。

## 实现

- **第 1 项（光标）**：`r183-sidebar-order.css` 去掉可拖动行与行主体的常驻 `cursor: grab`；平时保持行/按钮原本光标，只有真正拖动（`.is-dragging`）时才 `grabbing`（拖动时整条侧栏也显示抓取光标，避免行间来回变）。拖动逻辑本身不变。
- **第 2 项（卡片左右留白）**：共享 `r183-project-rail.css`：使用项目卡列的页面（成员管理/看板/文件与 Git/搜索与收藏）左内边距收到 **16px**，`--project-rail-inner` 也从 8px 改为 **16px**。实测「侧栏→卡片」=「卡片→分隔线」= 16px（1360/1873 两档、四页一致）。文件页 `.page.fg-page` 原有更高特异性的 `padding:0 0 18px`，用同特异性选择器覆盖。
- **第 3 项（√ 图标）**：看板单卡归档按钮图标由 `x` 改为 `check`；`data-zs-board-remove`、位置与行为不变。看板范围内该按钮 hover 由危险红改为成功色（√ 是「收起/完成」语义，不像删除）。
- **第 4 项（短提示）**：单卡归档按钮 `title="归档"`、`aria-label="归档 #N"`（无编号时「归档」）；「归档本项目」「归档全部」的 title 同步缩短为同名短句。
- **第 5 项（去房间筛选）**：删除看板筛选行的「房间」下拉与按房间过滤（列表/计数改为当前范围全部房间；卡片 meta 仍显示房间名）。旧链接带 `roomId` 进入时用 replace 清理一次、不再弹「筛选范围已变化」。筛选行保留：共 N 项 / 撤销 / 刷新 / 归档全部，并固定不换行。
- **第 6 项（文件与 Git 项目卡列）**：`FilesGitPage` 改为 `.page.fg-page > .project-split`：左栏项目卡列（`data-zs-files-project`，顺序跟随侧栏拖动偏好），右列保留原 topbar、Git 面板、文件双栏/Git 面板；删除顶栏项目下拉。点卡片 `focusProject` + 打开目标项目文件页（页签保留）——实测切项目前后 `.main`/`.fg-topbar` 左缘差 **0px**、无横向溢出、无左侧位移。项目卡 meta 显示「Git 仓库/非 Git 目录」。
- **第 7 项（搜索与收藏项目卡列）**：改为同样的两栏；左栏第一张固定「全部项目」（=侧栏可见项目，`data-zs-library-scope-all`）+ 每个未移除项目一张卡；删除「范围」三选一下拉。点「全部项目」只切本页范围（scope=visible）；点项目卡同时切换当前项目（`focusProject`，侧栏与标题栏同步）。切项目会清空旧「会话」筛选（旧 conversationId 属旧项目，留着必然查空）。
- **第 8 项（Git 未初始化提示）**：删除文件/Git 页「此文件夹未初始化 Git」信息面板；顶栏 Git 页签的「未初始化」小字、其它失败/错误面板保留。
