# R120：文件容量、头像与自动重试

用户要求移除 R119 表中与文件大小、数量有关的限制，头像默认显示，自动重试改为 5 次。本轮直接修改现有流程，没有新增设置或输入按钮。

## 当前行为

| 用途 | 本轮修改 |
| --- | --- |
| 上传与托管读取 | 移除文本、图片、PDF、Office、CSV 的固定字节上限，以及原始字节/base64 参数中的对应长度门槛；移除托管副本 64MiB 读取上限 |
| 图片和头像 | 移除图片单边、像素面积和头像文件大小限制；头像原图保存，不强制缩成 96×96；默认显示头像，已保存的开关选择保持 |
| 项目文件 | 文件树完整列举，不再只显示前 500 项；全文预览、原件读取、另存为取消容量拦截；桌面另存为 64MB 限制同步删除 |
| 解析与预览 | 移除 PDF/PPT 页数、Word 段落、工作表数、行列、单元格长度、CSV 行数及完整缓存文本大小的固定限制；ZIP 条目/解压字节、静态 PPT 页数/图片/SVG/JSON 容量限制同步移除 |
| 生成文件交付 | 移除每轮 12 文件/64MiB，以及按格式设置的单文件大小限制；完整详情 Markdown 同样可以保存为附件 |
| 修改快照 | 默认保存完整可撤销内容，移除单文件 8MiB 和环境变量文件数门槛；正式命令不再把旧 maxBytes 参数当作容量上限 |
| 文件与修改详情 | 文件、附件及改动集列表完整读取；改动详情不再截前 100 文件或只提供每侧 256KiB 文本 |
| Git | 状态/差异完整收集，移除 200 项状态、50 文件差异和差异字节门槛；文件暂存数量、冲突文本容量限制移除；大文件校验读取完整内容 |
| 导出与远程下载 | 移除 200 资产/256MiB 门槛；远程命令请求不再以 48MiB 拦截文件内容，下载校验整包后完整输出 |
| 自动重试 | 临时网络、限流或服务故障最多自动重试 5 次，即包含首次在内最多 6 次尝试；重启继续原计数，显示与事件记录共用同一常量 |

解析进程的内存、截止和并发调度仍按现有设置运行；模型每轮的上下文读取窗口保留。文件原件、预览和导出读取完整内容，模型输入会标明实际读取范围。格式损坏、路径越界、哈希不匹配、无权限、用户停止和执行结果待核对仍按实际情况处理。

只读格式补交沿用既有独立流程；此次 5 次重试调整针对临时网络及模型服务故障。已有业务写入的失败不会自动重做业务操作。

## 历史文档缓存

新的完整预览缓存以 `completePreview` 标记区别于旧版。预览会重新生成完整缓存；模型输入兼容结构、哈希、解析器版本均有效的已知历史缓存，保留旧截断事实，避免升级后仅因缓存口径变化阻断历史附件。旧表格窗口之外的内容不被当成已读取。

## 使用

头像默认显示。到“设置 → 外观”，找到自己或 AI 成员，点“选择图片”上传 PNG、JPEG 或 WebP，点“恢复默认”恢复。图文手册及 19 张示例截图同步更新。

临时故障的重试次数会显示在原任务运行详情中；等待与计数跨重启保留。五次重试后仍失败时，保留原因与已有成果，可在原对话继续。
