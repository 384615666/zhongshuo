# R183 用户九项界面反馈（成员管理 / 任务看板 / 侧栏排序）

日期：2026-11-05。版本：0.1.3-beta.28（与 R182「房间查询超时与协调成员停住」合并统一打包）。
本轮只改前端展示与交互（`src/ui/hifi`），不改 daemon 命令合同、不改数据库 schema、不迁移用户数据、零真实模型调用。

## 用户反馈（2026-11-04，截图 3 张）

1. 项目和房间应该可以上下拖动调换位置。
2. 成员管理里项目的切换卡片左边留白比右边多好多，不对称不好看。
3. 成员管理里去掉项目名称（截图红框「默认项目 / 7名成员」），成员数量放在左边的项目卡片里。
4. 成员管理里去掉「扫描本机 AI」，扫描本机 AI 应该在点击「添加 AI」时触发。
5. 成员管理里「刷新」和「添加本机 AI」放到搜索同一行。
6. 成员管理的 AI 卡片里，去掉「由本机默认配置自动添加，可随时修改」、去掉 ★协调者 标识、把「编辑资料」放到「AI 设置」里。
7. 成员管理的模板卡片里，去掉「启用」「…bypassPermissions」「▽执行程序」。
8. 成员管理的模板卡片里，点「在本项目中创建」应出现添加 AI 界面，只是预先帮填好模板里的值。
9. 任务看板里添加和成员管理一样的左边项目卡片，最上方为「全部项目」卡片，用来代替范围的筛选。

## 实现

- **第 1 项（侧栏拖动排序）**：新增 `src/ui/hifi/data/listOrder.ts`——本机本项目/房间显示顺序偏好，持久化 `localStorage` key `zhongshuo.nav.listOrder.v1`，只存 ID 数组（校验/去重/上限 500；坏数据回退默认顺序）；顺序语义=已保存顺序优先、未记录 ID 按原顺序追加；`App.tsx` 侧栏项目行与房间行接 HTML5 拖放（拖到目标行上半/下半=插到前/后，`drop-before/after` 指示；⋯/+ /图钉/展开箭头按下不启动拖动；房间只允许同项目内拖动；置顶房间区不参与）；`actions-nav.ts` 置顶项目时同步把项目提升到本机顺序最前（取消置顶不动位置）。只改显示顺序，不发 daemon 命令、不改项目/房间数据。
- **第 2 项（左栏留白对称）**：新增共享样式 `styles/r183-project-rail.css`：页面内边距 24/40 时，项目卡到页面左缘与卡到右栏内容的留白都等于 24/40（rail 内边距 8 + 列间距 16/32）。成员管理与任务看板共用，两页不再各写一套左栏几何。实测旧→新：1360px 宽 24/36 → **24/24**；1873px 宽 40/36 → **40/40**（差 0）。
- **第 3 项（去标题、成员数进卡）**：删除右栏 `.members-head` 整块；成员数进左栏当前项目卡 meta 行「N 个房间 · M 名成员」；成员数按 `projectId` 缓存（沿用房间数缓存的做法，切回已看项目不闪、未知不写 0）；归档/移除/目录失效仍以轻量 note 与卡片 flag 如实提示。
- **第 4 项（扫描并入添加）**：删除「扫描本机 AI」按钮；点「添加 AI」先 `member.discoverDefaults`（按钮显示「扫描本机 AI…」），刷新成员/房间投影后打开统一添加弹窗；扫描失败也继续打开并保留可读说明；说明按内容去重（原每个真实渠道各回一条相同 skipped 文案会重复 4 行）。同步 `pages/Room.tsx` 与 daemon `projectWriteAccess.ts` 里仍指向旧按钮的用户文案。
- **第 5 项（动作入筛选行）**：「刷新」「添加 AI」移入 `.page-filters`（搜索与状态下拉之后、左对齐，沿用 30px 行高规则）。
- **第 6 项（AI 卡精简 + 资料并入 AI 设置）**：AI 卡不再显示自动生成的说明「由本机默认配置自动添加，可随时修改」（字面量精确比对；手填说明保留）、删除 ★协调者标签、删除「编辑资料」按钮；名称/说明编辑移入「AI 设置」弹窗（`BindRuntimeModal` 新增可选 `allowProfileEdit`，成员详情页行为不变）。保存顺序：资料有改→`member.update`（返回新 revision）→配置有改→`member.setRuntime(expectedRevision=新 revision)`；只改一项就只写一项；资料已存但配置失败/未知时弹窗保留并分开说明，重试不会重复写资料；头像保存逻辑保留。
- **第 7 项（模板卡精简）**：模板卡只留 名称 + 渠道/模型 + 「编辑…」「在本项目创建…」；启用态不显示「启用」，停用态用极轻「已停用」保留可用性；删除说明、权限、执行程序 details。
- **第 8 项（模板创建走添加 AI 界面）**：`AddMemberModal` 抽成独立组件（`components/AddMemberModal.tsx`），支持 `prefill`；模板卡创建回调交回页面打开同一个「添加 AI」弹窗，预填名称/说明/渠道/模型/执行程序/权限/思考等级/头像，提交走 `member.create`；删除 `CreateFromTemplateModal`，模板面板不再调用 `memberTemplate.createMember`。
- **第 9 项（看板左栏）**：`TasksBoard.tsx` 改为与成员管理相同的两栏：左栏 `全部项目`（`data-zs-board-scope-all`，代替原「范围」下拉）+ 每个未移除项目一张卡（`data-zs-board-project`，显示项目任务数，未知不显示 0）；删除「范围」「项目」两个下拉，保留房间筛选/计数/撤销/刷新/归档全部；点卡只改本页数据范围（URL `replace` 同步），不切换侧栏 active 项目，与成员管理语义一致。
