# R136：DeepSeek Harness 与 Pi 运行时

用户要求按 DeepSeek Harness → Pi 的顺序实施。新增两种本机执行渠道，沿用成员、普通任务、协作派发、停止、恢复、成果校验与调用台账；未新增默认成员，也未改写已有成员或运行记录。

## 实现与使用

统一渠道目录位于 `src/contracts/runtimeKinds.ts`。成员创建、设置、详情、模板和后台校验使用同一目录；模型、思考等级和默认程序随渠道切换，保留原权限而不自动升级。后台工厂、生产/全局默认、受管进程、配置指纹、协调者选择、真实调用台账、批次及模拟环境保护均覆盖两种新渠道。

### DeepSeek Harness

首版核对官方 npm `@deepseek-ai/dsh@0.2.1-rc.5`。`packages/dsh-runtime` 是原创 MIT 连接组件，通过 `zhongshuo` profile 使用官方模型、工具、agent 循环和会话持久化。未复制 OpenDesign 源码，未把其 profile 或协议冒充上游通用接口。

协议为 JSONL v1：`--zs-probe`、`--zs-models`、`--zs-stdio`；每轮独立进程，输入使用 stdin。握手绑定 runtime/protocol，执行消息绑定 requestId。模型与思考等级从本机 Harness 查询；接收真实文本、工具活动和用量。只接受明确的完成终态，max-tokens、空结果、错误输出及会话归属不符不会成功。续接必须载入原始 session，缺失或目录不符不会自动新建替代会话。取消覆盖启动与运行窗口，结果输出等待官方 flush/dispose。

构建命令 `node scripts/build-dsh-runtime.mjs` 生成 tarball、校验清单和独立安装脚本。手动执行 `node scripts/setup-deepseek-harness.mjs --install`，只安装至 `zhongshuo` profile，并核对官方版本、归档 hash 和安装后握手。便携包附带 `ZhongshuoDual/runtime-tools/deepseek-harness/setup.cmd`，使用包内 Node 执行相同安装脚本。安装脚本不安装官方 DSH，不把凭据保存到众说，不在应用启动时自动安装。

### Pi

首版核对官方 npm `@earendil-works/pi-coding-agent@1.4.0`。外部 CLI 使用 RPC，每轮独立进程；使用明确 UUID 和众说专用 session 目录。启动先核对 `get_state` 的 UUID、路径及空闲状态，再发送 prompt。冷续接前读取原会话 header 并核对 UUID 和真实目录，缺失或歧义明确拒绝。长期指令通过临时文件传给原生 `--append-system-prompt`，不混入用户正文，也不把长提示词放进命令行。

`prompt` 接受回执和 `agent_end` 都不视为完成；等待 `agent_settled`，再核对最终助手的 stopReason。重试、工具结果、错误、取消和用量分别映射。费用是 Pi 根据费率估算的值，标记 estimated；不称实际账单。模型发现使用离线、无会话并禁用扩展/技能/模板的 RPC 查询，不发送 prompt。

Windows / Node 24.16.0 的官方 Pi 1.4.0 在原生 read 工具完成后立即 EOF 可触发 libuv 断言。对照试验：100ms、300ms 延迟各两次均退出 0；仅等待 get_state 回执后立即 EOF 的两次仍崩溃。众说对 Windows Pi 有工具活动的轮次延迟 300ms 关闭 stdin，保留真实 close 证据、退出超时与受管进程保护；不把延迟视为退出确认。原始失败及对照证据保留，未改官方 CLI。

## 状态和权限边界

新渠道首版仅允许 CLI 原生完整权限。只读分析、项目受限编辑、图片及工具禁用的格式修复暂不支持，执行前明确拒绝。已有 Claude/Codex 权限和历史配置指纹兼容保留。新执行端不会借切换渠道把旧只读任务提升为可写。

会话冲突保留全部实际 reported ID 供私信核对，不能冒称原生续接。执行进程无 provider 终态退出时，仅报告进程事实，由 worker 收口 UNKNOWN、保留恢复保护；不因 kill 或退出码自行生成确定失败。受管进程仍按 Windows Job Object 的实际身份与退出证据登记。

能力表保留按组合认证的口径。本轮使用真实官方程序和本地固定响应验证传输、生命周期与生产接线；不把这些结果写成真实供应商模型的质量、权限或识图认证。
