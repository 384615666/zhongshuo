# 精简后的整改清单

日期：2026-10-25。状态：**用户已明确批准实施；结果见 [R109实施记录](../../reviews/r109-simple-implementation-20261025.md)。**

这份清单取代上一版52项推荐与两套界面原型。上一版把过多问题变成了新增界面，增加了学习和操作负担。现在只保留下面7件事；私信独立上下文是沿用现状，不算新增任务。

## 现在留下的7件事

| 留下什么 | 具体怎么做 | 对应原项 |
| --- | --- | --- |
| 点X退出时提示 | 只在点窗口X准备退出时做一个简短确认，取消或退出。不给设置页再加退出管理，不加工作清单和后台模式。 | U01 |
| 看清已选文件夹 | 在现有项目选择位置显示已选文件夹路径。去掉上一版“欢迎页／上次项目／指定项目”三选一方案。 | U05 |
| 建房沿用默认AI | 沿用现有默认AI设置，创建时直接默认选中；需要时就在原有成员选择里调整。不再加“调整安排”、协调者选项或配置摘要。 | U11 |
| 完整操作手册 | 补齐真实已有功能的入口、操作步骤、结果和常见问题；随版本更新。使用现有离线手册交付方式，这轮不新做帮助中心和入口矩阵。 | U08 |
| 消息与任务按要求执行 | 输入界面不变。让模型理解谁做、什么顺序，接通已有派发和交接；完成状态反映实际完成情况。“继续”就继续原要求。 | U17–U19、U26 |
| 现有入口去对地方 | 修正现有按钮、搜索结果和通知的错误落点；已在回复串里就不再显示“打开回复串”。查询找到消息时直接去那条消息。不增加发送历史页、快捷入口或新按钮。 | U24、U30、U39、U43、U45 |
| 展示和内容错误直接修 | 查询成功后收起原查询块；旧成果正常读取；引用选区保留全文；旧计时器不清掉新错误；现有重复状态、冗长配置说明能删就删。不加字数条、诊断区、版本选择或新状态条。 | U15、U29、U31、U35、U49、U50 |

“谁做、先后顺序”由模型理解，不在输入框增加收件预览、顺序设置、识别提示或新的正则规则。模型使用已有成员身份与派发能力执行，不能仅在回复里说“已交给另一位”而实际没有派发。

U19用一句话解释：**让Claude分析、再让Codex核对，只有Claude做完时，不能把整件事标成完成。** 修现有完成判断即可，不增加验收设置、检查器或步骤面板。

U21保持原样：**新建私信就是独立上下文。** 撤掉新标题、私信搜索、继续最近会话提示等附加设计。

## 这轮撤掉什么

| 撤掉的方向 | 处理 |
| --- | --- |
| 草稿箱、长期保留、容量管理、清理改造 | U02、U03本轮不做，不因为旧方案定为高优先级就继续塞进来。 |
| 数据迁移、统一启动器、备份扩展 | U04、U06本轮不做。U04原指已有项目和历史，不是未发送内容；这次不会据此删除已有数据或改保存规则。 |
| 项目准备卡、成员范围说明、AI状态整合、权限影响说明 | U07、U12–U14撤掉。真实失败沿用现有报错，不常驻一堆内部状态和防御性解释。 |
| 记住上次房间、范围统一、当前安排 | U09、U10、U20撤掉。不增加导航记忆、范围提示或安排摘要。 |
| 私信列表升级、返工主按钮、评论派工、成果主动作重排 | U21的扩展、U22、U23、U25撤掉。继续用现有私信与原串追问。 |
| 占用任务入口、跨页发送账本 | U27、U28撤掉。不加另一套列表；只处理已有查询块和原消息落点的问题。 |
| 文件查找、对照模式、恢复按钮、版本另存选择 | U32–U34、U36撤掉。不把展示修复扩大为文件工作台。 |
| 搜索现场记忆、私信筛选、归档续查、看板来源筛选、待办重排 | U37、U38、U40–U42撤掉。保留原有界面；已有搜索结果点错位置的窄修另列在上表。 |
| 通知例外管理、配对引导、离开表单确认、全站键盘重构 | U44、U46–U48撤掉。不作为本轮新功能或重构项目。 |
| 新保存状态、预算说明与设置扩展 | U51、U52撤掉。U15只精简已有文字，U16保持现有操作。 |

## 实施边界

- 本轮只实施上表7项并同步手册，不恢复旧的界面扩张方案。
- 逐个核对必要性；已经正确的行为不为统一风格而重做。
- 不新增收件标签、输入提示、模式选择、顺序配置、阶段条、主页面板、诊断区、影响预览或额外确认。用户允许的X退出提示是本轮唯一新增确认场景。
- 暂缓的是改造建议，不是删除已有功能或已有数据。尤其不擅自清理聊天、文件、草稿、备份。
- 旧报告保留作排查证据，旧优先级不再代表本轮施工范围。52项对应的最新处置见 cut-decisions.json。
