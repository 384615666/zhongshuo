## 1. 气质定位

**清新轻量的团队工作台**：浅白色系的底、蓝绿两色的点缀、安静的排版。第一眼像"干净的团队任务收件箱"，不像后台模板，也不像色板。

明确排斥：企业后台模板感、彩色标签墙、大面积高饱和色块（含整块渐变外壳、渐变背景）、"什么都很重"的堆装饰（粗体+灰底块+渐变+彩色底座同时上）、2015 年代灰色控件风。

---

## 2. 设计原则（六条）

1. **布局先于装饰**。任何"不好看"先查布局（分主次、宽度分配、防挤压），再谈颜色和圆角。禁止用缩小正文的方式迁就工具栏。
2. **视觉重量有预算**（§3.7）：渐变、加粗、彩色、灰底块都是"重量"，同屏总量受限；正文永远是全屏最安静、最易持续阅读的一层。
3. **渐变只在两处**：品牌标记与主发送按钮。其余一律实色——作者名实色、导航图标素色、胶囊/徽标/激活线实色。
4. **状态三通道**：状态 = 图标 + 文字 + 颜色，缺一不可；图标语义不得挪用（§6 状态词表）。
5. **主池与回复串分工**：主池只放摘要，全文只在回复串；当前上下文有明确选中态。
6. **一切数值实测**：色值对比度（WCAG）与面差（L*）用脚本核算后再写进规范。

## 3. 色彩系统

### 3.1 浅白五级面（浅色为默认；零染色，不带青绿/蓝色倾向）

| 令牌 | 值 | L* | 角色 |
|---|---|---|---|
| `--bg-canvas` | `#F0F2F5` | 95.4 | 窗体基底、栏间缝 |
| `--bg-sunken` | `#E9ECF0` | 93.3 | 凹陷：引用块、嵌套内容 |
| `--bg-panel` | `#F6F7F9` | 97.2 | 结构面兜底（标题栏实用白玻璃） |
| `--bg-subtle` | `#F4F5F8` | 96.5 | 面内浅条 |
| `--bg-surface` | `#FFFFFF` | 100 | 内容面：卡片、面板、浮层 |

交互面：`--bg-hover #EDF0F4`、`--bg-active #E4E8ED`、`--bg-selected #E4F0F4`（蓝绿淡染）、`--bg-scrim rgba(15,20,28,.34)`。

**面差硬指标**：相邻两级 ΔL* ≥ 2；卡内嵌套块与卡片 ΔL* ≥ 6；卡片与画布用"底色差 + `--shadow-card` 柔层阴影 + 1px 发丝轮廓"三者合计定义边界（浅白底下允许低差面，但阴影与轮廓必须在）。

|---|---|---|
| `--bg-canvas` | `#0E1013` | 4.6 |
| `--bg-sunken` | `#0A0C0F` | 3.3 |
| `--bg-panel` | `#121519` | — |
| `--bg-surface` | `#181B21` | 9.7 |
| `--bg-subtle` | `#20242B` | 14.1 |

交互面：`--bg-hover #23272E`、`--bg-active #2A2F37`、`--bg-selected #17242B`。深色铁律：面亮度上限 L* ≤ 18、禁大面积亮块、描边用量减半、彩色换深色专用值。

### 3.3 文字四级（实测对比，浅色最坏承载面对白 / 深色对面）

### 3.4 蓝绿方向（主色实色 + 品牌渐变）

| 用途 | 浅色 | 深色 |
|---|---|---|
| `--accent`（链接/选中/焦点/主色件） | `#2E76AE` | `#7AB8DE` |
| `--accent-hover` / `--accent-soft` / `--accent-text` | `#256391` / `#D9ECF7` / `#2E76AE` | `#93C8E8` / `rgba(122,184,222,.14)` / `#7AB8DE` |
| `--green`（成功/正向） | `#22815E` | `#5FBE96` |
| `--green-soft` / `--green-text` | `#DCEFE6` / `#22755A` | `rgba(95,190,150,.12)` / `#5FBE96` |
| `--grad-brand`（**仅品牌标记与主发送钮**） | `linear-gradient(135deg,#7FB6D8,#6FC4A2)` + 深字 `--grad-ink #18323A`（≥8.8:1） | 同左 |

**渐变硬约束**：全界面渐变只允许两类件——品牌标记（≤24px）与主发送按钮；其他任何元素（作者名、头像、图标底座、胶囊、徽标、激活线、背景）一律实色。渐变两端的文字对比 ≥ 4.5:1。

### 3.5 语义色（只留给真状态）

| 语义 | 浅色 | 深色 | soft 底 |
|---|---|---|---|

| `--danger` 失败/冲突/破坏性 | `#B3564C` | `#E28C82` | `#F8E8E6` / `rgba(226,140,130,.12)` |
| `--success` 完成/验证通过 | 用 `--green` | 用 `--green` | 用 `--green-soft` |

### 3.6 成员实色（头像底 / 归属条 / 作者名三处同源；白字与彩名对比 ≥4.8:1）

| 令牌 | 浅色 | 深色 | 默认成员 |
|---|---|---|---|
| `--m-codex` | `#2A7A66` | `#4FA88C` | Codex |
| `--m-claude` | `#2F6E9E` | `#6FA0C0` | Claude |
| `--m-codex2` | `#5A7382` | `#8598A4` | Codex #2 |
| `--m-human` | `#2E76AE` | `#6FA8CE` | 人类/你 |

**作者名是实色**（不是渐变字）；"名签变色"（标签化彩色名牌）仍然禁止。禁止用于背景块、按钮、状态。

### 3.7 视觉重量预算（治 P8"什么都很重"）

同一屏内：

| 重量件 | 配额 |
|---|---|
| 渐变件 | ≤ 2 类（品牌标记 1 + 发送钮每条输入 1） |
| 650 字重 | ≤ 1 处（页面标题） |
| 600 字重 | ≤ 5 处（卡片/消息标题、作者名、主按钮、选中行标题） |
| 灰底块（bg-sunken 等成片底色） | ≤ 2 处（引用/嵌套内容），且不得"卡中卡中卡" |
| 彩色小件（实色胶囊/徽标/状态点） | ≤ 6 处 |
| 描边矩形（`--border` 及以上对比） | ≤ 5 个（发丝轮廓不计） |

超出即减，减法顺序：先减装饰（渐变→实色、彩件→中性）→ 再减加粗 → 最后才允许动布局密度。

## 5. 空间与几何

### 5.1 间距刻度（4pt 八档）

`--sp-1..8 = 4/8/12/16/20/24/32/48`。组件内禁止刻度外数字。节拍：组内 < 组间 < 区块间；控件横向 padding `--sp-3`；卡片内边距 `--sp-5`（20）；卡间距 `--sp-3`；区块间距 `--sp-7`；内容距窗边 ≥ 12px。

### 5.2 圆角刻度

| 令牌 | 值 | 用途 |
|---|---|---|
| `--r-xs` | 6px | 代码片、kbd |
| `--r-sm` | 8px | 小徽标、方章、图标按钮 hover 面 |
| `--r-md` | 12px | 输入框、内嵌块、列表行 |
| `--r-lg` | 16px | 卡片、面板 |
| `--r-xl` | 22px | 模态 |
| `--r-full` | 999px | 胶囊：按钮、标签、徽标、输入条 |

按钮与输入条统一胶囊；容器比内嵌块大一档。

### 5.3 阴影与轮廓

| 令牌 | 用途 |
|---|---|
| `--shadow-card` | 卡片/输入条柔层浮起（唯一的静态阴影） |
| `--shadow-pop` / `--shadow-modal` | 浮层 / 模态 |
| `--ring` | 聚焦环 |

轮廓三级：`--border-subtle #E5E8ED / #252A31`（发丝轮廓、卡内分隔）、`--border #D7DCE3 / #333A44`（同色容器嵌套）、`--border-strong #C0C6D0 / #464E5A`（交互控件）。规则：卡片默认 1px 发丝轮廓；**卡内元素禁止再描边**；高对比描边（`--border` 及以上）每屏 ≤ 5 个矩形。

## 6. 图标与状态词表

1. 图标：16px 网格、1.5px 描边、圆端点；导航图标**素色**（`--text-3`，无彩色底座）。
2. **状态词表（语义不得挪用）**：

| 状态 | 图标 | 文字 | 色 |
|---|---|---|---|
| 执行中/进行中 | `play` | "执行中" | accent |
| **运行中**（runtime 占用） | **`activity`（脉冲）**——**不得用勾号**（勾 = 已完成） | "运行中" | green-soft 系 |
| 排队/待审阅 | `clock` | "待你审阅" | warning |
| 已完成 | `check` | "已完成" | green |
| 失败/冲突 | `lock`/警示图标 | 文字说明 | danger |
| **只分析** | **`eye`（必须带图标）** | "只分析" | neutral |
| 无状态标签 | 无 | "#14""讨论" | neutral |

3. 状态 = 图标 + 文字 + 色三通道，缺一即返工。

## 7. 动效

时长 120/180ms 两档，缓动 `cubic-bezier(.2,0,0,1)`；只允许淡入淡出、≤8px 位移、展开收起、进度四类；禁闪烁与无限循环（不确定进度细环除外）；`prefers-reduced-motion` 下全部归零。

## 8. 布局系统（v4.3 核心章，治 P9）

### 8.1 三栏骨架与宽度分配（1372×872 基准稿）

```
┌────────────────────────────────────────────────────────────┐
│ 标题栏 48px（白玻璃 + 品牌标记）                              │
├──────────┬──────────────────┬──────────────────────────────┤
│ 侧栏     │ 主池 380px        │ 回复串（弹性）                 │
│ 240px    │ 摘要 + 输入条     │ min 440 / 无上限（弹性吞余量）  │
└──────────┴──────────────────┴──────────────────────────────┘
```

- **主池 380px 是起点值，不是固定答案**（合理区间 360–400）：只放摘要行，不给它更多宽度去堆长文；宽度必须按**真实任务标题与输入内容**实测校验（v4.5 实测：三条真实标题整行显示、元数据行不截断、输入行 ≥20 字可用，故维持 380；若真实数据出现标题两行仍截断或输入行过窄，上调到 400）；
- **回复串弹性**：`flex: 1 1 auto`，`min-width: 440px`，**不设 max-width——超宽窗口的余量由回复串吞掉**（面板铺满到窗口右缘，禁止右侧留空洞）；当窗口 ≥1568px 时，回复串内部内容列限宽 800px 居中，保证阅读行长（与 §3 行宽上限 68–76 字符一致）；
- **实现注意**：布局与断点规则写在样式表组件规则**之后**（同选择器后写覆盖前写，否则布局会被组件规则吃掉）；内容列居中用 `align-self: center; width: min(800px, 100%)`，不要依赖 `margin: auto`（弹性交叉轴上不可靠）；
- 侧栏 240px + 分隔 8px 固定；**禁止把固定宽度的压力全部转嫁给主池**，也禁止内容定宽后把余量裸露成空洞。

### 8.2 断点与切换条件

| 视口宽 | 布局 |
|---|---|
| ≥ 1080px | 三栏全开：侧栏 240 + 主池 380 + 回复串弹性（1080 下回复串 ≈452 ≥ min） |
| 900–1079px | **侧栏收 56px 图标轨**（隐藏标签/徽标），主池 380 不变，回复串拿回空间 |
| < 900px | **回复串全幅专注模式**（主池与分隔收起） |

### 8.3 窄窗防挤爆规则（硬性）

1. 标题类元素：`min-width: 0` + `text-overflow: ellipsis`，禁止被挤没；
2. 徽章/状态胶囊：`flex: none` + `white-space: nowrap`，禁止竖排折行；
3. 输入区（v4.5 双行）：输入行独立成行（2 行起、自动扩展），模式/工具/发送在次行，内部件 `flex: none` + 输入 `min-width: 0`；任何断点下**输入区与发送按钮必须完整可见**；
4. 每栏 `min-width` 兜底（主池 340、回复串 440），触发后走 §8.2 切换而不是继续压缩；
5. **超宽窗口规则**（≥1568px）：余量由回复串面板吞掉、内部内容列限宽 800px 居中；禁止任何栏定宽后把余量裸露为背景空洞；
6. 徽标同行文案预留宽度：摘要行第二行的文案 + 徽标总宽不得超过行内可用宽，宁可精简文案也不许徽标被裁切。

### 8.4 页头分主次

第一行：页面标题（20px/650，`nowrap`）+ 弹性间隔 + 紧凑动作（未读胶囊、⋯ 菜单）；第二行：协调者/元信息（13px/400，`--text-3`）。低频操作（房间设置等）收入 ⋯ 菜单；**不许为了放下按钮折行标题或缩小正文**。

### 8.5 主池摘要行（回复串打开时的默认形态；v4.5 重做——标题识别优先）

两行式，**标题独占第 1 行**（15px/500，最多两行 line-clamp，不与任何控件同行抢宽）；第 2 行 = 元数据（13px/400）：任务号方章 + 状态标签 + 回复数 + 时间（右对齐 mono）。全文、引用、长内容**只在回复串**。禁止把编号/状态/时间塞回标题行——摘要列表的第一职责是让用户认出是哪个任务，不是摆齐控件。

**当前任务选中态**：`--bg-selected` 底 + 3px `--accent` 实色左条 + 标题升 600。**不再放「回复串已开」微标**——选中背景已经表达了这层关系。

### 8.6 回复串分工与去嵌套（治 P2 残留）

1. **嵌套 ≤ 1 层**：禁止"外卡片套内卡片套灰底块"。分工计划这类结构 = **纯排版块**：标题行（图标 + 标题 600 + 说明）+ 子任务列表（发丝线 `--border-subtle` 分隔、零底色、零描边）+ 尾注（无底色）。
2. 灰底块（`--bg-sunken`）只允许两种场景：被引用的原文（root-msg）、代码/引用内容。系统说明、计划尾注等一律无底色。
3. **系统说明默认折叠**：标题行 + 一行预览（line-clamp 1）+ 「展开」按钮；长说明不默认全文展开。
4. 串内详情页签（回复/成果/活动/成员/任务详情/运行详情）保持；激活 = 实色下划线 2px。

### 8.7 输入区（主池与回复串各一条，独立、互不共享草稿；v4.5 重做——撤回一行式）

双行容器（圆角盒，不是胶囊）：**第 1 行 = 输入行独占**（textarea 2 行起、随内容自动扩展，约 8 行后内部滚动）；第 2 行 = 模式 chip（`#任务·自动` / `↳ 跟进 #n·自动`）+ 右侧低频工具（@、⋯ 菜单——**附件/讨论/次数/计划模式等收入此菜单**）+ 主发送钮（渐变件）。placeholder 提示草稿自动保存。**输入区首先让人写东西**：禁止把模式/工具/发送与输入文字挤在同一行；"低频工具收菜单"指的是收纳入口，不是把输入区压成一根胶囊。

### 8.8 文件预览状态（点对话中的文件名；v4.4 引入，v4.5 重做列宽与任务上下文）

点回复串里的文件名（行内代码样按钮，如 `components.md`）进入「当前任务对话 + 文件预览」状态：

- **主池暂时收起**（任务池只是隐藏，不是关闭；关闭预览即恢复原三栏布局），侧栏与标题栏不变；
- **左侧保留当前任务完整对话**：消息、分工计划、系统说明、串内详情页签与回复串独立输入条原样保留——**禁止用文件预览替换对话历史**；
- **任务上下文不许丢**（v4.5）：对话顶栏第 1 行 =「返回开发大厅」按钮（仅预览态显示，点击 = 关闭预览 + 主池恢复）+ **完整任务标题**（不许只剩编号和被截断的原消息）；第 2 行 = 编号 + 状态标签 + 时间；
- **右侧文件预览**：文件标签页（逐个可关；关掉最后一个标签 = 关闭预览）+ 路径栏（**路径 + 版本徽标**，如 `docs/components.md · v3 · 10:45 更新`）+ 预览正文（Markdown 渲染 / 代码只读）；
- **关闭恢复**：面板 ×、Esc、或「返回开发大厅」，主池与原布局立即恢复；
- **列宽按可用空间分配**（v4.5）：两栏可用空间（视口 − 侧栏 240 − 分隔 8）**默认对半分**——文件默认拿到约一半（例：2000px 窗口下两栏各 ≈876px），禁止"对话吞掉余量、文件锁死 520px"；
- **调整宽度**：分隔条可拖，预览宽 320–1200px；任何宽度下**给对话保底 440px**；**阅读限宽放在内容内部**（对话内容列 / 预览正文各自限宽 800px 居中），不得把"限制文字行宽"变成"把空间锁在空白里"；
- **窄窗切换**（<1200px）：不并排、不挤栏，改「对话 / 文件预览」单栏切换（对话侧永远保留输入框）；
- **硬性禁止**：任何宽度下不得出现"侧栏 + 主池 + 对话 + 预览"四个狭窄栏位并排；预览打开时主池必须收起，窄窗必须走单栏切换。

## 10. 深色主题

`:root[data-theme='dark']` 整组切换（§3.2/3.3/3.4 深色列）。要点：正文软白不用纯白（14.2:1）；弱提示对比 ≥3.5:1；彩色换深色专用值（成员色换亮一档实色）；`--grad-brand` 不变（粉彩在深色上自然发光）；粉彩件贴近黑面板时必须降明度（防"糖果亮块"）。

---

## 11. 视觉疲劳专章

1. 疲劳三角各断一角：密度走舒适档、阅读文字 ≥13px、描边低对比（§5.3）。
2. 对比度舒适带：正文 11:1–18:1、辅助 ≥4.5:1、弱提示 ≥3:1、描边 1.3:1–1.6:1；禁纯黑白。
3. 高饱和面积法则：饱和色块高 > 28px 或连续面积 > 4000px² 必须降柔底（≤14% 透明度）。
4. 零闪烁；动效总面积每次 ≤ 屏幕 1/4。
5. 阅读工效：正文 15px/1.7/≤76ch、长文行高 1.8、数字 tabular-nums、滚动不抢焦点。

---

## 12. 可访问性

对比度下限执行 §11.2（WCAG 2.2 AA）；键盘 Tab 全可达、焦点环 `--ring` 不被裁切；目标尺寸 ≥ 28px；200% 缩放不破版、字号 rem 跟随系统；`prefers-reduced-motion` 生效；状态三通道保证色盲可读（§6）。

---

## 13. 质感细节

像素对齐（1px 描边落整数坐标）；数字 tabular-nums 右对齐；`::selection` 淡染；图标同一网格同一描边；文案动词开头、状态词表统一、全角标点；禁止渐变背景、玻璃拟态滥用、emoji 图标、彩色进度条、卡片悬浮动画。

---

## 14. 验收清单

**自动**
1. 样式文件零裸色值（仅 tokens 白名单）；间距 ⊆ {4,8,12,16,20,24,32,48}；圆角 ⊆ {6,8,12,16,22,999}；
2. WCAG 脚本：正文/辅助/弱提示/图标/焦点环/渐变两端全部达标；
3. 面差脚本：相邻面 ΔL* ≥ 2、嵌套与卡片 ≥ 6；
4. **渐变计数**：全屏渐变件 ≤ 2 类（品牌 + 发送钮）；
5. `prefers-reduced-motion` 归零断言。

**目测（每轮浅/深各一套，且必须含窄窗）**
6. **1372×872 与 1100×872 两档截图都过关**：任务标题整行可读、输入区与发送钮完整可见、无竖排徽章（§8.3）；
7. 加粗岗位表（§4.3）逐处核对；正文是全屏最安静的一层；
8. 视觉重量预算（§3.7）逐项数；
9. 嵌套 ≤ 1 层、灰底块 ≤ 2、卡内无描边子容器；
10. 状态词表（§6）逐个核对图标语义（勾号只属于"已完成"）；
11. 主池摘要行 = 标题独占（≤2 行）+ 元数据次行，选中态（底色 + 左条 + 标题加重）成立；全文只在回复串；
12. 深色：无亮块、无糖果块、弱提示可辨；
13. 文件预览态（§8.8）：完整任务标题 + 返回开发大厅可见、路径含版本、两栏默认对半分、对话含输入框、窄窗单栏切换、无四栏并排。
