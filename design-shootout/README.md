# 众说 · 打开回复串界面 —— 三套视觉规范对照

用同一个界面（截图里的「开发大厅 · #14 回复串已打开」）落地三位 AI 各自的设计规范，
**同一份 DOM、同一份内容、同一套图标**，只有样式不同，便于你直接评判。

## 怎么打开

双击 `index.html`（Chrome / Edge）。

| 操作 | 说明 |
|---|---|
| 顶部「三套并排 / A / B / C」 | 并排对比，或单看某一套（快捷键 `0` / `1` / `2` / `3`） |
| 顶部「浅色 / 深色」 | 一次切换三套的深浅主题（快捷键 `D`）—— 三套都实现了深色 |
| 顶部「并排 / 1:1」 | `1:1` 按设计稿原生 1372×872 显示，用于放大看像素细节 |
| 每栏「单独打开 ↗」 | 新标签页打开该方案，可再切 1:1 全屏看 |

## 三套方案

| | 方案 | 规范文件 | 主张 | 本页面的关键差异 |
|---|---|---|---|---|
| **A** | Mimo | `docs/design-spec-candidates/zhongshuo-frontend-design-spec-zcode.md` (v4.3 合并版) | **清新轻量的团队工作台**：布局先于装饰、视觉重量有预算、渐变只在品牌+发送钮 | 浅白五级面；主池固定 380 摘要行 + 选中态三件套、回复串弹性 min 440（三档断点 1080/900）；分工计划去外卡嵌套、系统说明默认折叠；加粗三级（650 页标题/600 标题作者名/其余 400-500）；状态词表（运行中=activity、只分析=eye）；正文 15px/行高 1.7/限宽 76ch |
| **B** | Kimi K3 | `docs/zhongshuo-visual-design-spec-v1.md` (v1.5) | **淡蓝+淡绿双主色、排版比例与主次分区**：主区纯白/侧栏浅蓝白、正文 15px、系统说明降级为状态行、蓝绿渐变主按钮（端点压深保可读） | 沿用现有 color token 命名；卡片内部禁止再描边；一屏描边矩形 ≤ 5；主阅读 15px/行高 1.65 |
| **C** | hy4 | `design-spec/DESIGN.md` (v1.0) + `components.md` + `tokens.patch.css` | **先能读再好看**：沿用现有颜色与命名，只补规则不改值；一切取值走 token | 颜色值与前两位基本同源（原型现状）；卡片保留 1px 描边 + shadow-sm；标签高 20、--fs-11、必须带图标；字号九档 / 行高四档 / 控件高度只 24·30·36 |

三套都对截图里原有的问题做了处理：彩色名签中性化、状态三通道（图标+文字+颜色）、
正文提到 14px、卡片去嵌套描边。

## 文件

```
design-shootout/
├─ index.html          ← 对比台（打开这个）
├─ mimo.html           ← 方案 A 单独页
├─ kimi.html           ← 方案 B 单独页（内含「任务对话 + 文件预览」状态：点对话里的 components.md 打开；可关闭恢复 / 拖拽调宽 / 窄窗 ≤980px 自动切换单栏；?fp=open 直达预览态，&pane=doc 窄窗默认文档）
│  kimi-preview.html   ← kimi.html 的同内容别名（仅为既有深链保留）
├─ hy4.html            ← 方案 C 单独页
├─ build.mjs           ← 由 _src/ 组装三个独立页
├─ build-index.mjs     ← 由 _src/ 组装对比台
├─ _src/               ← 源文件（共享骨架 + 三套规范 CSS）
└─ _shots/             ← 渲染出来的浅/深对照图
```

> 三个 HTML 都是**完全独立**的单文件（CSS 内联、图标为内联 SVG sprite），
> 不依赖 hifi-prototype、不需要起服务。深色通过 `?theme=dark` 切换。

## 与既有原型的关系

**本目录新增，未改动任何现有原型文件**（`hifi-prototype/`、`prototype/`、`docs/*.html` 均未触碰）。
这里的 HTML 是为了「看规范长什么样」而独立重写的渲染样本，不是原型的迁移分支。
