components.md — 组件清单与规格

本文件由任务 #14 产出：视觉规范 v1.5 的组件级落地清单，按「容器 / 导航 / 反馈 / 输入」分组。

容器

  • .card 白卡 + 发丝边 + 16px 圆角；内部禁止再描边，嵌套 ≤ 2 层
  • .bubble 分工计划卡：卡内子任务用 --bg-surface-3 沉底块
  • .sys-card 系统说明降级为状态行（12px / surface-2），细节按需展开

导航

  • 页签 = 分段控件（灰槽 + 白激活块 + shadow-sm），不使用下划线
  • 侧栏当前项：淡蓝晕染 --bg-selected + 主色文字，无硬竖条

反馈

  • 状态 = 图标 + 文字，颜色是第三重冗余；同屏语义色元素 ≤ 2 处
  • 警示条：soft 底 + 图标，无框无竖条

DESIGN.md — 设计原则

双主色：清透蓝 #3b9eff 为主、薄荷绿 #22c08a 为辅。密度来自布局，不来自小字号。

背景层级

侧栏浅蓝白（--bg-app）≠ 主区纯白（--bg-surface），两者必须可区分；深色反向分层：侧栏最深 → 主区 → 卡片。

主次分区

主池负责扫描，回复串负责阅读与操作；文件预览打开时主池收起，但对话历史原样保留。
